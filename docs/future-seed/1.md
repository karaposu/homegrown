# Possible Breakthrough: Stage-2 Custom Loop Composition

The standard worker loop runs a fixed pipeline (Su → S → D → I → C) as **stage 1**. After stage 1, the system has accumulated context about the problem — it understands the question better than at start.

**Stage 2** would be a meta-loop-composed worker-loop variant — assembled from the same disciplines but in a problem-specific shape:

- chained Innovation runs if stage-1 candidates were too narrow,
- re-Surfacing if the territory was under-mapped,
- multiple S→D passes if the partition was wrong,
- repeated Innovation + single Critique across all if a niche problem demands broader candidate coverage.

The breakthrough: the disciplines themselves give the loop enough cognitive capability to **design its own stage-2 structure programmatically** based on stage-1 artifacts. Stage 1 is static; stage 2 is generated from what stage 1 surfaced.

This is meta-loop territory — a specialization where the next move isn't "select a standard worker-loop," but "compose a problem-specific worker-loop variant" assembled on the fly.

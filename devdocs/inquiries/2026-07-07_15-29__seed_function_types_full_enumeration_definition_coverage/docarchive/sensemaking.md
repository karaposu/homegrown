## Phase 3 — Ambiguity Collapse

### Ambiguity 1 — What must the types COVER?

**Strongest counter-interpretation:** coverage = the WHOLE definition (usable/anchored/gated/deferred), so the types must each account for all four properties.
**Why it fails (structural):** usable/anchored/deferred are shared by *every* seed regardless of function — they are the genus, not the differentia. Making the function-types "cover" them is vacuous (all types trivially satisfy them). The only part of the definition that *discriminates by function* is the gate's informativeness (what makes this seed news). So coverage-of-the-definition operationalizes as coverage of the gate's epistemic-effect space.
**Confidence:** HIGH.
**Resolution:** The coverage target is **the gate's informativeness-space** — "the ways a seed can be news about a load-bearing thing."
**Now fixed:** the types partition epistemic-effects. **No longer allowed:** treating the shared properties as function-discriminators. **Depends on this:** the derivation dimensions (presence, confidence).

### Ambiguity 2 — THE COUNT: is it two, three, or more? (the center)

**Strongest counter-interpretation (FOR folding back to TWO):** provocation (confidence-down) is not a distinct type — "learning your design X is flawed" is just *learning something new* (the flaw / the needed fix), i.e. an inspiration wearing a negative sign. Novelty already covers it.
**Why it fails (structural):** two independent grounds.
  (1) *The seed's content is about the PRESENT, not the absent.* A provocation-seed's content is "X (which you HAVE) may be flawed" — it modifies your confidence in a present thing. The *fix* is a different, later object (a downstream inspiration the provocation triggers — the lifecycle-link, S2). Collapsing provocation into "the fix it triggers" is a stage-error: it confuses the seed with its downstream consumer, exactly the error the 14-26 finding warned against for seed↔innovate-trigger.
  (2) *The action is opposite.* Decisive test: does confidence-down route the same action as anything already typed? Affirmation (confidence-UP) → **CLOSE** a question (stand down, don't-rebuild, spend confidence). Provocation (confidence-DOWN) → **OPEN** a question (re-open a settled matter, raise an investigate-item). These are **opposite actions**. A single type cannot route two opposite actions — so confidence-up and confidence-down cannot be one type, and confidence-down is not inspiration's action (BUILD a new thing) either. Three actions, three verbs: **BUILD / CLOSE / OPEN.**
**Also tested — FOR merging to TWO-with-a-bidirectional-confidence-type** (inspiration + "confidence-move"): fails on the same decision-vs-label test — "confidence-move" would route two opposite actions (close and open), so it is not one type. The direction is type-defining precisely because it flips the action.
**Also tested — FOR FOUR+:** probe the edges. *Absent-negative* ("X is not worth having") = confidence about a decision you hold (the not-having) = distributes to affirmation/provocation on that decision. *Neutral-new-property* ("X connects to Y") = gaining the absent connection = inspiration; ("X has a hidden cost") = confidence-down = provocation. *Re-prioritization* ("X matters more/less") = confidence-up/down on X's importance-attribute = affirmation/provocation once "confidence" ranges over any load-bearing attribute, not just soundness. **All edges distribute into the three; no fourth ACTION emerges.**
**Confidence:** HIGH on three (the internal-gap anchor + the opposite-action test are structural, not elegance-only); the residual uncertainty is population, not structure.
**Resolution:** **THREE function-types** — inspiration (BUILD), affirmation (CLOSE), provocation (OPEN) — derived from presence × attribute-confidence-direction.
**Now fixed:** the count is three; the confidence dimension ranges over any load-bearing attribute. **No longer allowed:** "exactly two poles" (refined); minting a fourth without a distinct action. **Depends on this:** the door-vs-type reconciliation; the priors re-test; the seed_generator routing.

### Ambiguity 3 — Is provocation's ACTION genuinely distinct from inspiration's "refine"? (prosecute hardest — where proliferation hides)

**Strongest counter-interpretation:** "investigate a flaw in X" = "refine X" (an inspiration development-kind), so provocation's action folds into inspiration after all.
**Why it fails (structural):** refine acts on a *known* improvement to an owned thing (you know what to change). Provocation does NOT yet know there is a problem, let alone the fix — its action is to **open the question "is X sound?"**, which is *upstream* of refine and can resolve three ways: to a refine (flaw confirmed + fix found), to an affirmation (investigated, X is fine after all), or to a build (X needs replacing). An action that is upstream of, and can terminate in, refine/affirm/build is not identical to any of them. Canon anchor: the Primitive RC *firing* is an **alarm that opens investigation**, not itself a fix — the harness's own architecture separates "detect the break" from "repair it."
**Confidence:** HIGH, with an honest note: the refine/investigate boundary is the closest of the three pairs, so Critique should prosecute this once more. But "open vs already-knowing-the-change" is a real structural gap.
**Resolution:** provocation's action (**OPEN-a-problem** / raise-an-investigate-item / lower-confidence-in-a-settled-thing) is distinct. It survives the anti-proliferation bar.
**Now fixed:** provocation is a real third type, not a relabel. **What changed in the model:** the anti-proliferation discipline AGREES to three (three distinct actions), so three is not proliferation — it is forced.

### Ambiguity 4 — Is provocation real if no provocation-seed has been harvested yet?

**Strongest counter-interpretation:** an un-exemplified type is speculation; don't mint it until a real one appears (YAGNI).
**Why it fails (structural):** coverage is about the SPACE the definition admits, not the current sample. The definition admits confidence-lowering news about a present thing; that cell exists whether or not it's filled. Precedent: affirmation was itself un-exemplified until paper 20 — and the *cost* of the old gate not having the affirmation-cell was that paper 20's mirror was un-scorable. An un-typed provocation-seed would be un-scorable the same way. Structural-forcing is the inclusion criterion; population is a monitoring signal, not an existence test.
**Confidence:** HIGH.
**Resolution:** include provocation structurally; flag it **monitor-for-population** (a frontier-type: real but un-exemplified). State the caveat plainly in the finding — do not present provocation as an observed phenomenon.

## (c) Phase 2–3 — Adversarial evaluation + verdicts

### C1 — T2 vs the actual invocation (the leak-closure test)
**Prosecution:** "appear to narrow coverage" reopens the exact judgment that leaked; and the real brief ("Production-task mode… generate (a)–(e)… Inversion is MANDATORY…") never SAYS "skip mechanisms" — would T2 even fire?
**Defense/Collision:** run the brief through T2: piece-list = seed-shape (allowed); mandated Inversion = extra attention (allowed); nothing grants coverage-reduction — and under T1 the standard is unconditional, so the run fires all seven REGARDLESS of what the brief omits. The leak dies not by classifying the brief but by making coverage brief-independent. The "appear to" clause is then unnecessary judgment — cut it.
**Verdict: REFINE → applied (R1):** T2's last sentence becomes *"If args conflict with this standard, the standard wins: the run fires all seven and notes the conflict in the ledger."* — no "appear to"; conflict-noting is IN ADDITION to compliance (the wording already said "runs full scale AND notes"). **Decidable: the actual invocation is now harmless under T1+T2 — the leak-closure test passes.**

### C2 — T1 vs the spec's cross-references (the identity test)
**Prosecution:** T1 replaces the "Minimum coverage / Systematic coverage" passage — but L353 ("minimum 1G+1F per Coverage Strategy"), L357 ("Minimum-mechanism mode: 1G+1F only — the Coverage Strategy's bare minimum"), and L393 ("does NOT replace the Coverage Strategy's per-seed minimum") ALL cite the minimum. Deleting it orphans three cross-references and undefines a legitimate methodology-mode.
**Defense/Collision:** confirmed by live grep — the break is real. The fix is redefinition-not-deletion: the minimum survives as a named floor-CONCEPT (mode-vocabulary needs it); the RUN-level standard becomes full-scale; and Minimum-mechanism mode becomes reachable only via the user's own words — which is *exactly consistent* with T1's skip clause (a user invoking "minimum sufficient" IS the user-words event).
**Verdict: REFINE → applied (R2):** T1 gains the compatibility sentence: *"The per-seed minimum (1 Generator + 1 Framer) remains defined as the Coverage Strategy's floor-concept that methodology-modes reference; invoking a below-full mode (e.g., Minimum-mechanism) is itself a user-words event under this standard — the ledger quotes the user's invocation."* All three cross-references survive.

## Phase 2 — Adversarial Evaluation

### Candidate A — The EXTEND verdict (with REFINE-level continuity) (principal)

**Prosecution (strongest case against):**
- *P-a (the F6 line — the key objection):* "EXTEND over-dramatizes. The hybrid shape (primary axis + attributes) is preserved; routelister just instantiates it with its own axis (kind) and attributes (grain, abstractness). Swapping the values of a preserved structure is the definition of REFINE. EXTEND inflates a content-swap into a frame-change."
- *P-b (the F1 line — user-perspective / specification-gap):* "routelister DOES have a fixed typology — kind×grain×abstractness is a fixed, closed, enumerable set. That IS a taxonomy. So premise-absence (D2) is false; routelister has a fixed taxonomy, just a smaller one — which pushes the verdict toward SAME/REFINE."
- *P-c (failure-case, F2):* "At least one attribute transfers — `intent` (exploration/refinement/closure) is essentially routelister's kind. Dropping it is making the 'content fully changes' story artificially clean."
- *P-d (the F4 line):* "'routeman = special case' is a forced parallel to the 16-41 input-contract finding. routeman's types are loop-moves; routelister's are concept-routes. Calling one a special case of the other is rhetorical symmetry, not structure."

**Defense (strongest case for):**
- *D-a (vs P-a):* the distinction is "the shape" vs "the logic." The 24 01-30 LOGIC was the whole operation — *take a fixed inherited taxonomy → surface its grouping → name families → attach attributes.* routelister changes the **premise** (no fixed taxonomy), the **object** (closed → open), the **operation-timing** (post-hoc pass → type-at-emission), and **100% of the content** (all 6 attributes drop). Only the abstract shape + the method survive. When premise + object + operation + content all change and only the meta-shape survives, that is a *generalization of the logic*, not a refinement within it. REFINE would be apt only if the operation stayed "categorize a fixed taxonomy" and the family-names/attributes were merely tuned — but the operation itself changes.
- *D-b (vs P-b):* kind×grain×abstractness is a fixed set of **dimensions (axes)**, not a fixed set of **routes (members)**. routeman's taxonomy was a fixed set of MEMBERS (the 16 types — what you pick from). routelister's members (routes) are open/territory-derived; only the axes are fixed. "Has fixed dimensions" ≠ "has a fixed taxonomy of routes." The 24 01-30 logic categorized MEMBERS; routelister has no fixed members.
- *D-c (vs P-c):* `intent` presupposes a loop-move (it is the intent OF a next-move-after-a-cycle); kind is a route's relation to the goal, independent of any loop. The resemblance is lexical, not structural — `intent`'s grounding (a loop-move) is absent for routelister. It is re-derived as kind from the 09-53 concept-definition finding, on a different (non-loop) grounding.
- *D-d (vs P-d):* instantiation-containment is structural, not rhetorical — apply routelister's general operation ("perceive concept-identities in a territory; type each route") to the territory "the 16 canonical move-types as a frozen list" → it yields routeman's situation. The general operation literally produces the special case when fed a frozen-list territory. **External calibration:** this is the same containment the 16-41 input-contract finding established for state⊆territory (an independently-reasoned prior) — the parallel is structural, not decorative.

**Collision:**
- P-a × D-a → **defense wins** on the operation-vs-shape denotation: "the logic" = the whole operation, which changes wholesale; REFINE describes only the surviving shape+method. EXTEND is the correct headline. Prosecution earns a REFINEMENT, though: the verdict must explicitly credit the surviving shape+method ("EXTEND with continuity," not bare EXTEND) — already present in Innovation's output. **D1: PASS** (EXTEND, continuity-credit required).
- P-b × D-b → **defense wins** via axis-fixity ≠ member-fixity. Residual: the verdict must state the "fixed-dimensions / open-routes" distinction explicitly (F1's REFINE→boundary) or a reader could mistake the fixed axes for a fixed taxonomy — present in Innovation's output. **D2: PASS** (with the fixed-dimensions/open-routes distinction required).
- P-c × D-c → **defense wins** (`intent` is loop-grounded; resemblance lexical). **D3: PASS.**
- P-d × D-d → **defense wins** (instantiation-containment; external 16-41 parallel). **D4: PASS.**

**Position:** **VIABLE region.** Passes all three CRITICAL dimensions (D1 headline, D2 premise-absence, D6 identity-coherence) under the high-stakes burden, plus D3/D4/D5/D7; the F1 (fixed-dimensions) and F6 (continuity-credit) refinements are folded in (both already present in Innovation's output).

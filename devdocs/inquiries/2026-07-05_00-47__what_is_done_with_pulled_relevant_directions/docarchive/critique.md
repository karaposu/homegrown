## Phase 2-3 — Adversarial Evaluation + Verdicts

### D1 · READ ≠ MEMORY (Q4/E1) — REFINE (R1, precision) — external-anchor fires
**Prosecution:** is "enabling vs constituting" word-play? A memory *system* includes its access paths — so the read is part of the memory, and "the read isn't memory" is a rhetorical trick.
**External-anchor (canon, quoted):** `docs/canon/sustained_traversal_loop_of_loops.md` — *"remember — traversal memory is updated (what was visited, selected, why, with what outcome)"* and the turn-invariant *"A revolution counts as a SUSTRALL turn when its selection-rationale is recorded."* The canon defines memory as a **record that is updated / recorded** — i.e., produced by **writes**. The Look-Up updates nothing.
**Collision → REFINE (precision):** the reframe holds — the **stored memory** (the record/state) is the writes; the read produces no record. But the prosecution has a fair sliver: a memory *system* does include its read paths. **R1: say "the read is not the *stored* memory" (not "not the memory system")** — the read is part of the memory *system* (its access path) but not part of the *recorded content*. This keeps the confusion-dissolving force (the user looked for recorded value inside a read; it isn't there) while being exact. Enabling-vs-constituting stands: the read makes the record *useful* (enabling); the writes make the record *exist* (constituting). SURVIVES with the precision.

### D2 · Q1 "real gap" — REFINE (R2, narrow the claim)
**Prosecution:** the ODI doc **deliberately** says *"It does not decide what to do next… it does not select."* That's a legitimate scoping-out, not an omission. Calling it a "gap" is uncharitable.
**Defense (ODI doc text):** the doc's §"Why It Helps" lists benefits of *surfacing* (not-losing / right-timing / bridging), and the walkthrough ends at *"surfaces… precisely when B needs it"* — it never states the operational payoff of *using* a surfaced direction. So the *choice* is legitimately punted, but the *payoff* is unstated.
**Collision → REFINE:** **R2: narrow Q1.** Not "the doc forgot something" — rather: *the doc specifies the mechanism and legitimately punts the choice (act or not), while leaving the operational payoff — what using a surfaced direction concretely buys — unstated. That's what the user is missing, and it's a fair thing to miss.* This is both more accurate and still validates the user (the confusion tracks a real unstated-payoff, not a misreading). Non-sycophancy in the charitable direction (don't overstate the doc's fault).

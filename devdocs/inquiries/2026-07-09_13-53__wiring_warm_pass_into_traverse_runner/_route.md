# Concept-map — wiring the warm pass into the traverse runner (within-concept index)

Iteration 1 (fresh). Nodes + links of the runner-wiring edit map and its onward field. (No process/control-flow state — that lives in _state.md.)

## Nodes

- **the-edit-map** — the 9-site (A-I) site→change map for `traverse/SKILL.md`; the whole design.
- **the-9-sites** — A pipeline notation · B Progress +Warm · C Skill-table +row · D the W loop subsection · E the conflict-block gate · F the operator-present mode · G the _state.md Warm Loop line · H RESUME mid-loop · I iteration reset + telemetry.
- **the-W-loop-block** — W's special transition protocol: the bounded re-surface loop (invoke warm → §8 termination check → re-surface incrementally & repeat → exit). Site D.
- **round-keyed-surface-sections** — each re-surface writes a delimited `## Re-surface round N` section into surfacing.md (the runner composes); the key amendment.
- **write-ahead-status** — the Warm Loop status field (looping-warm | looping-surfacing) so mid-loop resume knows a surface was in-flight.
- **the-conflict-block-gate** — after the loop settles, before S: severe content-conflict → operator-present blocks+poses / autonomy flags+proceeds; user-overridable. Site E.
- **the-operator-present-mode** — a runner mode, default present / autonomy opt-in; governs the gate. Site F. The one genuinely-new runner notion.
- **the-re-surface-asymmetry** — first Su = _branch.md (cold-MQ2-driven); re-surfaces = runner-formulated territory+purpose+bias from the warm MQ2.
- **the-manual-structural-check** — articulate_warm.md gets a manual structural-check fallback (like routelister), the checker lacking a warm mode.
- **W-framing-not-answer** — the completion-check includes articulate_warm.md as produced, but answeredness keys off critique.md (W is upstream framing).
- **APPLY-the-edit-map** — apply all 9 sites + amendments to traverse/SKILL.md; the dominant onward; CLOSES THE GAP.
- **validate-warm-e2e** — run a real /traverse post-wiring; check the design-doc §13 graduation criteria.
- **the-surfacing-append-capability** — an optional upstream fix (give /surfacing a native append mode); worked around by round-keyed sections.
- **the-non-standard-transition-pattern** — Routelister + the warm-loop = two non-standard discipline transitions; nascent (N=2).
- **the-5-inherited-commitments** — §9 unconditional-first-surface · §8 termination-enforced · §11 incremental-accumulating · F14 warm-emits/runner-acts · F13 operator-present-only.
- **minimal-extension** — the wiring reuses the runner's existing grammar; cheapness inherited from prior work.

## Surfaced Items (relevance-tagged)

### Region A — the Physarum profile (honesty-bounded)

- **A1 — one giant cell (syncytium) [LOAD-BEARING]** ★solid. *Physarum polycephalum* in its plasmodial stage is a single enormous cell with many nuclei and no internal cell walls — one continuous bag of streaming cytoplasm. → Structurally UNLIKE the mycelium (many walled hyphae forming one organism): Physarum is *more* one-body and *less* multi-compartment. The name *polycephalum* ("many-headed") = many advancing fronts of one cell, not many bodies.
- **A2 — it flows and migrates [LOAD-BEARING]** ★solid. The plasmodium is motile: cytoplasm streams, the whole mass can crawl, and it can *abandon a location entirely and relocate.* → Unlike the mycelium, which GROWS (extends new tips, the built body largely stays), Physarum can *pull its whole investment out* and move on.
- **A3 — shuttle streaming: the oscillation is the computation [LOAD-BEARING]** ~partial (rhythm solid; "computation" framing is interpretive). Protoplasm oscillates back and forth (rhythmic contraction waves); the flow redistributes toward attractants and away from repellents. The network's optimization emerges from this flow, with no controller. → a rhythmic *sample-and-redistribute* pulse.
- **A4 — adaptive tube network: thicken the productive, prune the rest [LOAD-BEARING]** ★solid (well-documented). Tubes carrying more flow thicken; tubes carrying less wither and are resorbed. Positive feedback builds efficient transport networks. → the "whole-network funds the promising front, prune the dead" picture, cleanly.
- **A5 — no brain [LOAD-BEARING]** ★solid. No nervous system; behaviour is emergent from flow + oscillation + local chemistry. → keeps the no-hero property.
- **A6 — the famous experiments [LOAD-BEARING for grounding]** ★solid as *results* / ⚠overclaim-risk on interpretation:
  - **maze / shortest path** (Nakagawa et al. 2000) — fills a maze between two food sources, then retracts to the shortest connecting path. → *explore-broadly-then-consolidate-to-the-optimum.*
  - **Tokyo rail network** (Tero et al. 2010, Science) — with food at the positions of cities, it grew a transport network comparably efficient/robust to the actual rail network. → a brainless network *computed* a near-optimal resource-distribution layout.
  - **anticipation of periodic events** (Saigusa et al.) — ~partial; slows in anticipation of a recurring cold pulse. Cite lightly.
  - **externalized spatial memory** (Reid et al. 2012) — leaves an extracellular *slime trail* where it has already been and *avoids* it, using the trail as external memory to avoid re-searching. → **[LOAD-BEARING for the over-integration fix].**
- **A7 — the cognition question [ANTI-RELEVANT / boundary]** ⚠overclaim-risk. Whether any of this is "intelligence / decision / learning" is debated. → cite the *behaviours* (path-finding, network-optimization, trail-avoidance); do NOT rest load on "the slime mold thinks."

### Region B — the head-to-head comparison axes (Physarum vs the mycelium)

- **B1 — structure [LOAD-BEARING].** Physarum: one syncytial cell (more unified). Mycelium: many walled hyphae, one organism (more multibody). → the mycelium is the richer "many fronts / multibody" picture the user cared about; Physarum is *more* one-body.
- **B2 — motion [LOAD-BEARING].** Physarum FLOWS / MIGRATES / can fully de-commit and relocate. Mycelium GROWS / extends / largely stays. → Physarum models *full withdrawal-and-relocation* of investment; the mycelium models *extend-reinforce-abandon-branch.*
- **B3 — memory [LOAD-BEARING, the pivot].** Physarum has TWO: the internal tube-network (live flow / current allocation) AND the external slime trail (persistent been-there record). Mycelium has ONE: the network (body = path-memory). → Physarum SEPARATES an external record from the internal flow; the mycelium FUSES them.
- **B4 — allocation [LOAD-BEARING].** Both reallocate a shared substrate. Physarum: thicken/prune tubes + migrate the whole mass. Mycelium: reinforce cords + abandon/recycle regions. → both are the allocation dimension; Physarum's is more dramatic (whole-mass mobility + demonstrated optimization).
- **B5 — grounding [LOAD-BEARING].** Physarum: demonstrated computation (maze, Tokyo rail) — an existence-proof that a brainless network optimizes. Mycelium: foraging, no sharp experimental existence-proof. → Physarum imports a slice of grounding the mycelium lacked.
- **B6 — the explore-consolidate rhythm [SUPPORTING].** Physarum's oscillation + the maze's fill-then-retract = *explore broadly, then prune to the optimum* — a vivid picture of a search that samples widely then commits. The mycelium's version (extend-then-reinforce) is present but less sharp.

### Region C — the two sharp-finding hypotheses (surface, don't pre-decide)

- **C1 — the over-integration FIX (test) [LOAD-BEARING].** The mycelium's over-integration wrinkle (15-56): it fuses memory and body/budget into one structure, where the project keeps the external corpus (memory) separable from live context/budget. Physarum's two-memory split — internal tubes (live) + external slime trail (persistent, external) — maps that separation *natively*: the slime trail is an EXTERNAL record used for anti-redundancy ("don't re-search where I've been"), exactly like the project's written corpus / route-index. → **candidate: Physarum FIXES the over-integration wrinkle.** BUT bound it: the slime trail is a *been-there anti-redundancy* trail, not a *weighted, proportion-kept findings* archive — so it maps the *anti-redundancy function* of the record, not the full record. A *partial* fix, honestly scoped.
- **C2 — the grounding IMPORT (test) [LOAD-BEARING].** The Tokyo rail is real evidence a brainless network computes a near-optimal resource-distribution network. Tested against the 14-23 grounding standard (civilization actually resolving mysteries / curing disease): Physarum's is a *smaller* existence-proof — a lab optimization, not a civilization. → **candidate: Physarum imports grounding-of-the-MECHANISM (brainless networks CAN optimize), not grounding-of-the-whole-architecture.** Real but lesser than humanity's; honestly a different tier.

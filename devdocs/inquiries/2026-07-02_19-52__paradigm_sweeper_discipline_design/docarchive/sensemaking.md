## Phase 3 — Ambiguity Collapse

#### Ambiguity A1 (guard a): Does the kill stand, revise, or fall?
**Strongest counter-interpretation:** "Paste the instruments into innovate's references or a protocols/ file — reach-for-ability without a tenth discipline; the kill stands."
**Why the counter fails (structural grounds):** each proposed host fails a different structural test. Innovate-references = the S1 hook (exists as a pending design; in-run scale; takes a seed — the S2 ask takes a practice with no seed yet). Protocols/ = runner-called, not user-invoked-with-artifact. Generic machinery (surfacing/routelister) = the kill's own named route, contract-true and **never once used** — because the instruments that make the operation THIS operation live in findings, not in any invocable thing. The kill's premise ("the enumeration machinery exists") was true of generic machinery and became false-in-the-relevant-sense hours later when the SPECIFIC instruments were created homeless.
**Confidence:** HIGH.
**Resolution — the kill is REVISED (inherited as confirmed-but-frame-revised):** what stays confirmed: a discipline must not duplicate generic enumeration machinery — so the sweeper's spec OWNS the paradigm-instruments and does NOT re-implement surfacing/routelister mechanics (where it sweeps, it does so as its own probe pipeline, which is not those disciplines' machinery). What revises: "no new skill needed" — superseded by the instruments' existence + homelessness + the zero-run evidence + the user pulling the extraction trigger (08-53 itself planned instrument-extraction on reuse). **Fixed:** the sweeper operationalizes the homeless instruments; duplication ban carried into the NOT-list. **No longer allowed:** framing the sweeper as generic enumeration. **Depends:** the spec citing the findings as its instrument-source.

#### Ambiguity A2 (guard b): SKILL or recipe/protocol — what does the form buy and cost?
**Buy (specific, not generic):** step-0 canonical reference = the instruments get a Baldwin-updatable home instead of rotting in findings; a failure-mode catalog the operation genuinely needs (candidates already visible: modal-map-only [stopping at probe 1], checklist-ossification [facets as boxes], family-hallucination [entries failing the membership test], anchoring [judging before every family has its batch], selection-creep [the map crowning a winner], scope-miss [skipping probe 0]); telemetry + verdict; the artifact contract (seed-ready entries); invocability (the reach-for-ability itself).
**Cost:** spec maintenance; skill-count growth; **formalizing a zero-live-run theory** — the real one.
**Confidence:** HIGH.
**Resolution:** the SKILL form, at **v0 explicitly-provisional**: the spec states its instruments are inherited from named findings with a live validation debt (the blind-topic ceiling), and commits to revision from the first invocation's evidence. Formalize-then-validate is acceptable here BECAUSE the first invocation is already scheduled and the spec says so.

#### Ambiguity A3 (guard c): The sequencing — sweep first, or the roadmap's first move first?
**Strongest counter-interpretation:** "Sweep → redesign memory → THEN pre-register and take the first turn on the new elegant logic. Why record turns into a shape you're about to replace?"
**Why the counter fails (structural grounds):** three independent failures. (i) **Window-physics:** the pre-registration file must predate the FIRST trace; the sweep's dives are traverse loops whose selections are precisely turn-shaped — running them first either wastes the turns (unrecorded — the starvation continuing) or records them (which requires the artifact, hence pre-registration, first anyway). (ii) **Shape-independence:** the thin record is one line (`chose · because · led-to → pointer`); every memory-architecture family that could win the sweep (log, ledger, graph, index, stigmergic, cache/warming) can ingest one-line choice records — the redesign replaces the architecture AROUND the records, not the record semantics; nothing recorded now is lost. (iii) **The convergence:** the sweep's N per-family dives on ONE territory with a cap is structurally THE LONG WALK (the roadmap's item 3) — running the memory-logic sweep AS the first sustained chain makes the user's desired work and the roadmap's recommended work the SAME work, with every dive a recorded turn feeding the Selector's gate.
**Confidence:** HIGH.
**Resolution — the staging:** (1) pre-registration file (hours; now-or-never); (2) the First Turn (minutes; the v0 thin record — and its selection can literally be "chose: build the paradigm-sweeper"); (3) build the sweeper (structural+process, on go); (4) **the first invocation = the traversal-memory sweep, run as the Long Walk** — one territory, N family-dives, hard cap, every turn recorded. The user's helper and the climb stop competing; each powers the other.

#### Ambiguity A4: The category answer.
**Resolution (HIGH):** an **eighth runnable SKILL** in the perception/enumeration class (with surfacing and routelister), invoked ON DEMAND upstream of loops — **not** a new member of the traverse pipeline (A→Su→S→D→I→C→R unchanged), not a protocol, not an innovate mode. Its identity guard: **enumerate-don't-decide** (it maps families; the consumer selects). The user's "even if it doesn't make sense as a discipline" resolves to: it makes sense as a SKILL-class discipline; what it must never become is a pipeline stage or a selector.

#### Ambiguity A5: Naming.
**Resolution (MED-HIGH, recommendation):** skill name **`paradigm-sweeper`** (the user's own word; agentive noun = the instrument), keeping **"Paradigm-Sweep"** for the S3 MTTP catalog member (the orchestration pattern). One sentence in the spec states the pair. Alternative (`/paradigm-sweep` for both, disambiguated by context) noted and disfavored for speech-collision.

## Phase 5 — Conceptual Stabilization

### SV6 — Stabilized Model

**Identity (the meaning layer):** *The paradigm-sweeper makes chart acquisition runnable. Given a stuck or unsatisfying topic, it recasts the topic as a practice ("whose practice, doing what?" — probe 0), then perceives and maps that practice's paradigm-families — the coherent, generative bundles of commitments available for approaching it — via the committed probe pipeline (schools → facet-walk → defaults → coherent combinations {established | frontier} → fashion-loosening). Its artifact is the paradigm-map: 5–9 basic-level entries, each a loop-ready seed. It enumerates; it never selects.*

**Should-be:** the six probes as the process spine; the 5+2 facet kit as probe 2's engine (heuristic prior, never checklist); the membership test as the family-filter; frontier candidates flagged and KEPT; each entry carrying the seed contract (practice-recast · commitment-bundle · exemplar-or-frontier · axis-positions · goal echo · a copy-pasteable seed block); the anchoring guard for multi-seed dispatch (a batch per family before judging any); v0-provisional status with the first-run-revises clause.

**Shouldn't-be (the NOT-list):** not a pipeline stage (traverse unchanged); not a selector (cross-family selection belongs to the consumer — the identity wall); not a candidate-generator (it maps families, not solutions — the dives generate); not the S3 MTTP (the catalog owns the orchestration); not an innovate replacement (the S1 hook stays innovate's own pending patch; the sweeper feeds charts to whatever generates); not a paradigm-SHIFT engine (acquisition, not replacement); not generic enumeration (the duplication ban carried from the revised kill); not a finished theory (v0; blind-topic validation debt inherited and stated).

**The staging:** pre-registration file → the First Turn → build the sweeper (structural+process on go) → **first invocation = the traversal-memory sweep run as the Long Walk** (dives-as-turns; the roadmap and the helper converge).

**Failure-mode + saturation report:** Status-quo bias — the kill was neither kept by default nor flipped by enthusiasm; it was revised on a dated premise with the ban carried. Premature stabilization — 7 perspectives; the risk perspective forced the v0-provisional mitigation. Anchor dominance — the model rests on quoted kill-text, the instruments' timeline, the zero-run fact, and the roadmap's physics, not on one anchor. Perspective blindness — the paste-counter and the sweep-first steelman were run at full strength; both extracted structure (the ban; the convergence). Clean-resolution trap — every collapse names its tested counter; A5 ships as a recommendation, not a certainty. Self-reference blindness — the design formalizes this session's own theory-work: countered by inheriting 09-30's validation ceiling verbatim and scheduling the live test as the first invocation. Ambiguities 6/6 (5 HIGH, 1 MED-HIGH recommendation). **PROCEED.**

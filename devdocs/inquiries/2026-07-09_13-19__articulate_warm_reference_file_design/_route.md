# Concept-map — articulate_warm reference-file design (within-concept index)

Iteration 1 (fresh). Nodes + links of the reference-file blueprint and its onward field. (No process/control-flow state — that lives in _state.md.)

## Nodes

- **the-reference-blueprint** — `references/articulate_warm.md` = a template-matched 6-section discipline reference; the whole design.
- **the-6-section-skeleton** — Identity · Components · Process Model · Quality · Output Contract · Execute (matches the discipline-reference template).
- **the-operational/canonical-split** — inline the operational SHAPE (imperative, runtime-runnable) / POINT the canonical DEFINITION (deep, not-reasoned-from-each-run). The organizing principle.
- **the-cheat-sheet-format-guard** — the cheat-sheet = op-name · warm-behavior · ≤3-word-reminder · pointer; labeled reminder-not-definition; drastically-smaller drift surface (not zero).
- **conflict-detection-fully-IN** — the one operation with no cold home → its full canonical spec lives here; the file's primary reason.
- **the-inheritance-boundary-short** — a short orienting boundary-statement (owns-X / inherits-Y→cold-ref); NOT an exhaustive manifest.
- **the-3+1-failure-modes** — Quality §4.2 = 3 conflict-detection modes (false-positive · over-flag · adjudicate-not-identify) + 1 trigger-gate mode (ignore-the-trigger→§9); cold's POINTED.
- **the-provisional-status-note** — the reference says "canonical operational spec; warm is provisional-until-exercised (design-doc §13)".
- **the-division-of-labor** — SKILL (thin wrapper, slims) / reference (canonical operational) / design-doc (rationale/provisional) / cold-reference (shared) — all pointed except the reference.
- **WRITE-the-reference** — create the file per the blueprint (the dominant onward; low-risk new file).
- **the-SKILL-slim** — the 9 steps canonicalize into the reference's §6; the SKILL becomes the thin wrapper (2nd ordered build step).
- **refine-§13** — update design-doc §13's "no new failure modes" to acknowledge the new modes.
- **the-inherit-and-extend-template-lens** — skeleton + inheritance-boundary + operational/canonical split, a reusable template for inheriting disciplines; modest, N=1.
- **fewer-sources-not-more** — a 4th file WITH consolidation = fewer places a fact lives (conflict-detection gets ONE home; the SKILL shrinks); user-driven.
- **the-3-priors** — 09-05 (thin-wrapper, premise-updated) · 09-48 (Item A+B) · 11-32 (holistic structure).

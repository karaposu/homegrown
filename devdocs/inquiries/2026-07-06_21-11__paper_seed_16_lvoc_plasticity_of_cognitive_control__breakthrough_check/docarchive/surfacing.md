## Paper FACTs (A-n) — verified against devdocs/paper_seed/16.md

- **A-1 (the frame it extends).** Paper 16 EXTENDS Russell & Wefald rational metareasoning (paper 15's VOC) + Shenhav's Expected Value of Control (EVC) with a LEARNING mechanism. Cognitive control's function: "to select and configure neural pathways so as to make optimal use of finite time and limited computational resources" (~18-20). Control specification = a "metacognitive decision problem" (~155).
- **A-2 (the meta-level MDP).** Control = a meta-level MDP M=(S, s0, C, T, r): states = beliefs (about environment + own internal state), control signals = actions, reward r(s,c)=u(X)−cost(s,c) (~178-192). Optimal control = the policy that "always chooses the computation with the highest expected value of computation (EVOC)" (~194-197). This is the SAME control layer paper 15 mapped (VOC), now in RL/MDP dress.
- **A-3 (THE NEW AXIS — learning/plasticity).** "an approximation to the EVOC can be learned from experience" (~234-236). The Learned Value of Control (LVOC): a FEATURE-BASED linear approximation of the Q-function (Eq 6), updated by approximate Bayesian regression (Eq 7), explored via "an exploration strategy similar to Thompson sampling" (Eq 8). Core claim: "the brain learns how to process information via **metacognitive reinforcement learning**" (~337-338). Learns "when to exert cognitive control, which controlled process to use, and how much effort to exert" (~16-17).
- **A-4 (feature-based prediction → TRANSFER).** The learned value is predicted from stimulus FEATURES (Eq 6: w·f(s)), so "all learning effects should transfer to novel stimuli that share the features that were predictive of the expected value of control" (~834-836). Transfer-via-shared-features is LVOC's distinctive empirical signature (validated on Bugg et al. picture-word transfer).
- **A-5 (options).** Strategies modeled as "options" (a policy + an initiation set + a termination condition); "elementary computations can be interpreted as options that terminate after the first step" (~215-224).
- **A-6 (self-control failure / over-control).** When the internal feature-model's assumptions are violated (value of control non-linear in features), "the control system's plasticity mechanisms may become maladaptive"; explains "why people sometimes overexert cognitive control even when it hurts their performance" (mal-transfer) (~921-943).
- **A-7 (control as gradual adjustment).** Control specification is gradient ascent from the previous trial's signal (Eq 13) → "the inertia of control specification," task-set inertia, switch costs (~513-524, ~944-952).
- **A-8 (integration claim).** LVOC "synergistically integrates" EVC (control specification) + rational-metareasoning strategy-selection — "augments the EVC theory with metacognitive learning and prediction... and augments rational metareasoning models of strategy selection with the capacity to specify continuous control signals" (~887-896).
- **A-9 (the numeric + neural + empirical machinery — QUARANTINE candidates).** The LVOC Q-approximation (Eq 6), the Bayesian-regression update (Eq 7), Thompson sampling (Eq 8-9), the drift-diffusion model (Eq 12/18), the control-cost/opportunity-cost functions (Eq 14-15), BIC model comparisons; the NEURAL cost model ("the cognitive opportunity cost of control is a consequence of overlap between neural pathways" ~544-545); the EMPIRICAL apparatus (Stroop/Flanker/visual-search; Rescorla-Wagner + Win-Stay-Lose-Shift baselines).

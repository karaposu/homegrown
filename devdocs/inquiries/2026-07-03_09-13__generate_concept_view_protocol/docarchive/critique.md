### C4 — The supersession walk's direction (the letter-check)
**Prosecution (the pass's material catch):** `refines:`/`supersedes:`/`corrects:` live in the NEW finding, pointing AT the old — tagging hit X as superseded requires findings whose frontmatter VALUE equals X's path: an **inverse lookup**. **Verdict: REFINE → applied (R4):** step 3 rewritten: whole-corpus frontmatter grep → inverse map → tag hits that appear as targets, with the refiner's path in the tag. *(The command now achieves what the step claims.)*

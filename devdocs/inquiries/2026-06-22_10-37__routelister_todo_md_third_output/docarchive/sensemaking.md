# Structural Sensemaking — Routelister `todo.md` (Third Output)

## SV1 — Baseline

## Phase 1 — Cognitive Anchor Extraction

**Constraints:**
- C1 — **"One enumerator, two controllers"** (SUSTRALL): routelister *enumerates*; the runner + orchestrator *decide/track*. The enumerator must not acquire a controller/memory function.
- C2 — **"Navigation sees; it does not choose."** routelister is the *eyes*, a *session* (fresh perception), not a standing tracker.
- C3 — Self-containment + write-once: routelister owns `routelister.md` (fresh per-run) + `_route.md` (perception cache). It must not own a mutable consumer-edited file.
- C4 — No-routelog-duplication; the done/parked slice already has a home.

**Key Insights:**
- K1 (the location) — tracking "visits, selections, rationales, outcomes" = **traversal memory = the orchestrator's organ**, explicitly **"zero instances at naming time."** This is where the user's need actually lives.
- K2 (the worth-it) — traversal memory is not a minor feature: it is the **SUSTRALL Tier-1 "first traversal-memory artifact ever,"** the **#1 named gap** ("nothing watches between inquiries yet — ≈0% system-detected"), the keystone the era-goal's first step sits on ("a turn counts when its selection-rationale is recorded into traversal memory"). **The user, fixing a ✓-column annoyance, independently re-derived the project's keystone.**
- K3 (the regeneration trap) — a routelister-emitted `todo.md` inherits the **same ✓-futility**: regenerated each run (clobbers edits) OR not (goes stale vs the new field). Decoupling into a file routelister still emits does not escape this.
- K4 (the clean decoupling) — real decoupling = the **consumer points AT routelister's routes by reference**; routelister emits nothing new and never tracks. The mutable record is a different organ.

**Structural Points:**
- S1 — three organ-separated surfaces: **routelister** (eyes: enumerate) · **routelog** (the existing done/parked engagement slice) · **traversal memory** (will: selections + rationales + outcomes across runs — to build).
- S2 — routelog ⊂ traversal memory: routelog records *done/parked*; traversal memory adds *why-selected* + *outcome*. The user's "editable table of routes with done-marks" overlaps routelog heavily; the *richer* cross-run record is traversal memory.

**Foundational Principles:**
- P1 — organ purity: a cognitive function (enumerate / decide / track) lives in one organ; mixing them is the architectural defect SUSTRALL's "one enumerator, two controllers" exists to prevent.
- P2 — at Level 0 the human IS the orchestrator; so the human's tracking artifact IS Level-0 traversal memory — owned by the human-as-orchestrator, not emitted by the enumerator.

**Meaning-Nodes:** enumerator-vs-controller · traversal-memory-as-keystone · the-regeneration-trap · organ-purity · Level-0-traversal-memory · decoupling-by-reference.

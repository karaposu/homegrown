## ★★P3 — THE VENTURE DEFINITION (the core)

### The canonical definition-block (principal candidate)

**KIND.** A venture is a **RUN** — one episode of the system in motion. It is not a system (that is SUSTRALL), not a capability (that is explfine's kind), not a pattern (an itinerary), not a capability-level (a tier), and not a single cycle (a turn).

**The three marks.**
1. **A specific purpose.** A venture is undertaken FOR something — a seeded aim the run answers to. The purpose is what fills the termination question's first slot ("enough for WHAT?"): it makes the venture's end *judgeable*. (It fills the slot; it does not solve the termination question — the measure, detection, economics, risk, decidability, authority, and resumability sub-questions remain open.)
2. **A particular thinking space.** A venture traverses a bounded, readable territory — the same P-condition canon already places on explfine ("any bounded, readable territory"). Not the whole of thinking space; a region of it.
3. **A beginning and an end.** A venture begins when its purpose is seeded (canon's input-form: "seed plus context") and ends when the pursued thread is **satisfied, deliberately abandoned, or handed off — never by timer**. Pauses are reversible (a venture can park a branch and recall it — the sample parked one for 32 days); "bounded" means ends-by-purpose, not never-interrupted.

**Tier-agnostic clause.** A venture is a run of the SUSTRALL-*shaped* system — hands (worker loops), eyes (navigation), will (selection/dispatch), memory — **at whatever tier the project stands**. The tier grades WHO carries the five cargos during it: seeing, selecting, dispatching, remembering, stop-judging. At Level 0 the human carries all five; the climb is the same venture-shape with cargos shifting onto the system.

**Identity: thread-continuity.** One venture = one continuously-pursued thread. The purpose may sharpen and re-frame through findings (the landscape is non-stationary; the map is built by traversing it) — continuity is carried by the record chain (continues-from / refines / corrects links) and the navigator's returning intention. A deliberate pivot to an unrelated thread starts a new venture.

**The exemplar.** `devdocs/traversal_sample.md` records one venture-token: nine days, ~60 traverses, one evolving-but-continuous thread (traversal memory → re-tool the generation machinery → return), run at Level 0 with the human carrying all five cargos. *(P6 guard: spot-check the sample on disk before the finding quotes it verbatim.)*

**Residuals, visibly carried.** (i) The pivot-boundary — WHEN a purpose-shift becomes a new venture — is answered at the meaning layer (thread-continuity + the record chain) but its determination *mechanism* is structural-layer work, deferred. (ii) The sample's end is read as purpose-satisfied (the re-tooling thread closed; harvesting resumes as the next pursuit) — the alternative reading (paused-at-waypoint) is noted, low-stakes.

### The one-line compression (the P3→P1 export; no new predicates)

> **venture — one bounded, specific-purpose run of the (SUSTRALL-shaped) system over a particular thinking space: many turns chaining many traverses; begins at a seeded purpose, ends by purpose — satisfied, abandoned, or handed off — never by timer.**

### Core-sentence wording variants (for the gate)

- **V-plain (plain-first):** "A venture is one bounded run of the traversal system: point the system at a particular thinking space with a specific purpose; it chains traverses — probing, seeing, deciding, dispatching, remembering, assessing — until the purpose is satisfied or deliberately let go. It begins, it moves, it ends."
- **V-marks (marks-first):** "A venture is a run of the SUSTRALL-shaped system distinguished by three marks: a specific purpose (the end is judgeable), a particular thinking space (a bounded readable territory), and a beginning and an end (ends by purpose, never by timer; pauses reversible)."
- **V-relation (relation-first):** "A venture is to SUSTRALL what one traversal is to /traverse — the run-unit one level up: where a traverse walks one question to one finding, a venture drives many traverses across one territory toward one purpose, and stops when the purpose says stop."

### Piece-level Inversion (meta-decision; assumption reversed: "venture is a RUN-kind")

**Inversion-candidate:** venture is an ACHIEVEMENT-kind — "venture" names the *capability* of running bounded purposeful runs (parallel to SUSTRALL's state-sense), so "reach venture" = attain-the-capability.
**What follows:** the sample could not be "one venture example" (one cannot instance an unattained capability) — direct contradiction with the user's sentence and collapse-1; and the ladder would hold two capability-rungs and no run-unit, reproducing the very hole the mint fills.
**5-test:** fails scrutiny (contradicts the coinage's own use) + fails fertility (re-opens the hole). **REJECTED.**
**Depth-iteration (system-level):** invert again — "the ladder needs no fourth rung because SUSTRALL, correctly understood, IS venture-capability: the system that can run ventures, sustained." This lands as a *strengthening restatement*, not a contradiction: it gives "SUStained" its missing object — **what is sustained is venture-running**. → Kept as an OPTIONAL relation-sentence for the gate: *"SUSTRALL is the system that runs ventures — and keeps being worth running (Sustained)."* Disposition: ACTIONABLE-optional.

The phrase names a property/target; the venture is its countable bearer — *one* bounded meaningful traversal, undertaken on purpose.
3. **itinerary / MTTP pattern = the PATTERN a venture may follow.** Canon: "itineraries — composed multi-loop journeys… many steps with a shape." Type vs token: the itinerary is the shape; the venture is a walked instance (which may also be improvised — not every venture follows a named pattern).

5. **turn / revolution = one CYCLE within.** One six-verb revolution selects and dispatches roughly one traverse; a venture contains many. turn : venture :: step : journey.
6. **"the walk" = the Movement Frame's presupposed object, now named.** The frame "types steps; it never scores walks" — it declines to SCORE walks, not to name them; its own steering-category is defined as "decisions ABOUT the walk." Naming the walk-unit is not scoring it; the compliance rule survives untouched. (Adding venture as a frame CATEGORY would be a structural-layer edit — not proposed here.)

**Compatible neighbors (patch-level absence check — lines added):** **inquiry** = one traverse's record-container; a venture's record = a *chain* of inquiry folders + their links (what the sample-compile reconstructed by hand). **episode** = the memory-kind vocabulary a venture's record instantiates (episodic → consolidates to semantic/canon). **tier/level** = orthogonal: any tier's system runs ventures; the tier grades who carries the cargos. **branch (BRANCH_INQUIRY)** = a within-traverse child structure — below venture-scale; distinct from nested ventures (horizon). **seed + context** = canon's name for a venture's *starting input* (worker_loop_logic §6).

**THE ADDITIVE CLAIM.** No existing term loses meaning; five gain a missing relatum (explfine a genus; the property a bearer; the pattern a token; the motion an episode-unit; the cycle a containing whole).

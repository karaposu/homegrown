## A. FACTs from the paper (quoted verbatim where load-bearing)

- **A-1 [core] — The thesis: no dedicated WM store; WM is EMERGENT.** "working memory functions arise through the coordinated recruitment, via attention, of brain systems that have evolved to accomplish sensory-, representation-, and action-related functions." "working memory may simply be a property that emerges from a nervous system that is capable of representing many different kinds of information, and that is endowed with flexibly deployable attention." FACT.
- **A-2 [core] — Storage = sustained activation of the SAME systems that represent the content (no separate buffer).** Principle one: "the retention of information in working memory is associated with sustained activity in the same brain regions that are responsible for the representation of that information in non-working memory situations, such as perception, semantic memory, oculo- and skeletomotor control, and speech comprehension and production." Overlaps with "the temporary activation of representations in long-term memory" (Cowan, Oberauer, Anderson). FACT.
- **A-3 [core] — Attention is the constituting mechanism.** WM "functions are produced when attention is directed to systems that have evolved to accomplish sensory-, representation-, or action-related functions." FACT.
- **A-4 [supporting] — Multiple encoding (principle two): the mind opportunistically recruits ALL codes a stimulus affords.** "humans opportunistically, automatically, recruit as many mental codes as are afforded by a stimulus when representing that stimulus in working memory." The phone number carries the speaker's voice, timbre, affect, room lighting, etc. FACT.
- **A-5 [supporting] — Control ≠ storage, AND control is not WM-specific.** PFC does interference/distraction mediation (sensory gating), attention/selection, flexible control, transformation/response-prep, motivation — not storage. "none of the control processes reviewed here are specific to or specialized for working memory... the control of working memory does not differ qualitatively from the control of any other behavioral or mental function." FACT.
- **A-6 [supporting] — The proliferation reductio: the standard model collapsed under its own success.** Every new empirical dissociation demanded a new subsystem → "a working memory system organized into hundreds (if not thousands or more) of domain-specific buffers"; a model of parsimony subverted "into an unwieldy organizational scheme that redundantly duplicates every representational system in the mind and brain." Remedy: stop positing separate systems; recognize the function as emergent from existing ones. FACT.
- **A-7 [peripheral] — Sensory gating: the keep-out, re-touched.** One hypothesized PFC contribution is "to control the gain of activity in sensory processing areas of posterior cortex... suppressing the sensory processing of potentially distracting information in the environment." (Postle in-press-b: "one function is sensory gating.") FACT. (Re-touches paper 3/7's encode-time keep-out residue.)
- **A-8 [quarantined] — The neural substrate + domain battleground.** PFC vs posterior storage, delay-period activity, single-unit electrophysiology, fMRI signal-change disputes, spatial-vs-object/faces-vs-houses dissociations, Brodmann areas, monkey lesions. FACT-in-paper but OUT of scope (MQ4): no brain, no visual buffer.
- **A-9 [supporting] — "Relabeling a system that already exists" is the paper's own anti-decorative test.** On positing an "articulatory loop" for order memory: to do so "would seem to needlessly relabel a system that already exists." FACT. (Strikingly parallel to OUR import test — the paper polices its own decorative relabels.)

## B. FACTs from our canon / prior findings (read verbatim this dive)

- **B-1 [core] — Paper 1: working memory is a genuine FOURTH KIND (a peer), affirmed as real dissociation.** Paper-1 finding: the four kinds are "working memory (a single traverse's live in-context scratchpad, discarded when it ends) / episodic / semantic / option"; and (Reasoning) "The four kinds as real dissociation... They are distinct kinds, not one thing viewed four ways." FACT. Paper 1 ALSO flagged a category-error — but specifically the *artifact* question: "does a transient thing need a durable artifact, or is forcing one a category error?"
- **B-2 [core] — Paper 2: WM = the context window = a CACHE over the backing store, holding only the loaded fraction.** Paper-2 finding: "The context window IS a working memory... A session can *reach* the entire repository... but can *hold* only a tiny resident fraction... The context window is a cache (fast, small, resident) over a backing store (the repo, vast, on disk)." And reach≠grasp: "a session mistakes what it can *reach* for what it actually *holds*... only the loaded fraction is live." FACT. **This is the KEY prior: paper 2 already frames WM as the loaded/activated fraction of {canon (semantic) + memory files (episodic/option) + repo (perception)}.**
- **B-3 [core] — Paper 2: the category-error was RESOLVED (snapshot distinction), and the WM kind was CONFIRMED-AND-THICKENED, NOT demoted.** Paper-2 finding: "the live working memory stays transient and artifact-less... durability, when needed, comes from snapshotting a different kind." Re-test: "the kind survives and is now *grounded*... and *thickened*... The kind survives." FACT. So our canon currently holds WM as a **confirmed fourth kind** whose substrate is the context-window cache.
- **B-4 [supporting] — reach≠grasp is a YES (regulative) import; the availability illusion; E1 (all memory machinery defends the reach/grasp gap).** Paper-2 finding: reach≠grasp is "a genuine second load-bearing import... regulative (the constraint the design serves)." FACT.
- **B-5 [supporting] — The primitive set holds Attention-pointer AND Working Memory as co-primitives.** `thinking_space_dynamics.md`: 11 typed primitives including Attention-pointer, Working Memory, Inhibition (response-suppression), Salience, Context-framing. FACT. (Paper 8 bears on the attention↔working-memory RELATIONSHIP — is WM downstream of attention?)
- **B-6 [supporting] — Paper 3/7's keep-out residue: the missing encode-time selective gatekeeping; context-pollution as a capacity tax.** FACT (paper-7 finding). Paper 8's A-7 sensory-gating re-touches this.
- **B-7 [core, method] — The import test + the harvest ladder + the forecast-first protocol.** Real iff NAMES-unnamed OR RESOLVES-a-pre-existing-confusion; ladder = generative / regulative / cluster / bounded-residue / confirming-plus (residue-sharpener) / confirming-nothing.

## Step 4 — Question Tree

**Q0 (root).** *What does the `rl.md` proposal require, what does it mean for RouteLister's existence, and are its changes regressions or improvements?*

### P1 — The capture rule (honesty first)
**Question:** What must RouteLister capture about a route's basis — as pointer or as excerpt — and under what honesty rule, and does that capture pass the yardstick?
**Verification criteria:**
- [ ] the never-invent clause is stated as the *governing* clause (it constrains A, B, D-recovered, and E), phrased beside §3.1 as the record-side twin of perceive-by-enumerating
- [ ] the **materiality determination** is specified: a reliance is material when removing the source would change the route's Move, Lands, WHY, or its inclusion (a basis, not decoration)
- [ ] the **pointer-vs-excerpt determination** is specified: pointer when a durable original exists in the project record or at an accessible location (path + section; URL + section; a location inside the artifact's own `## User Input` or the inquiry's `_branch.md`); excerpt only when none does (conversation turns, including mid-pipeline turns; standalone conversation-fed runs)
- [ ] the excerpt form is proportionate: one relevant sentence, speaker or source type, one line of context; never the conversation
- [ ] no redundant capture: a route whose basis is already a path in Touches needs no separate citation; `## User Input` is never re-copied
- [ ] the "original not recovered" mark and the LAYER 1 mode ("basis unrecoverable" → FLAG, route kept) are defined, with one telemetry count
- [ ] requirement stated at spec / run / ecosystem level; verdict + guard recorded (expected: improvement, guard = honesty outranks precision; the naive precision-first version is the one regression path)

### P2 — The citation annotation
**Question:** What must each citation say beyond its location — role, source-vs-interpretation, and state — and does that stay within RouteLister's boundaries?
**Verification criteria:**
- [ ] the role clause is in the Touches-qualifier shape ("(establishes the audience)", "(corrects the earlier reading)"), integrated with the `(bc …)` convention rather than duplicated
- [ ] the quote / paraphrase marks are defined; an assistant summary is never presented as the user's words; "source-said ≠ source-true" is explicit
- [ ] the **state determination** is specified: an as-of date or version is required only when the route's claim is about the source's *state* (what it said at the time), not merely its existence; no general version tracking
- [ ] no annotation may name another route (route → source only)
- [ ] requirement stated at spec / run level; verdict + guard recorded (expected: improvement; E stays a criterion)

### P3 — The two homes
**Question:** Where do reusable references live in the per-run map and in the cumulative index so that they stay intelligible across routes and across runs without dangling?
**Verification criteria:**

- [ ] stale-flag-not-delete applies to references whose target no longer resolves; perception governs on re-run
- [ ] the inter-concept-edge prohibition is shown to hold (shared sources are a compactness device, not a stored relation)
- [ ] verdict + guard recorded (expected: improvement in the map; the index is the one place a regression is easy — a source database)

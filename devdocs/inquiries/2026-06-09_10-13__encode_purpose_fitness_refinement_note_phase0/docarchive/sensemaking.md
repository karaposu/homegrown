## Phase 3 — Ambiguity Collapse

### Ambiguity 1: Single-locus vs multi-locus refinement note

**Counter:** Multi-locus (Phase 0 main + Phase 3 back-reference at constructive-output note) ensures the structural test integration is visible at both loci.

**Why counter fails:** Multi-locus is structurally heavier and reserved for cases where the failure surface SPANS distinct loci (IFP needed it because the failure has half at Phase 0 [no frame prosecution] and half at CONCLUDE [preservation-verification framing]). Here the severity-CALIBRATION is at Phase 0 only; the constructive-output AS test is content the new Phase 0 note REFERENCES, not co-located with. Single-locus + firm cross-reference is structurally cleaner.

**Confidence:** HIGH.

**Resolution:** **Single-locus.** Phase 0 step 4 with cross-references outward. Ancillary D (back-reference at Phase 3 constructive-output note) can be added as a COULD if symmetry is desired but is not required for correctness.

### Ambiguity 2: Defer-with-direction encoded now or deferred to process inquiry?

**Counter:** Defer-with-direction is RUNTIME behavior (how does critique behave when invoked on an ambiguous-purpose candidate?); it belongs to a process-layer inquiry.

**Why counter fails:** Defer-with-direction is also STRUCTURAL: it specifies the spec's OUTPUT when the purpose-fitness test cannot be applied. The refinement note IS the structural articulation of the principle; saying "and when the principle can't be applied, do X" is part of the structural specification. A practitioner reading the note without the defer-with-direction clause would conclude critique should silently refuse or silently modify — both fragile.

**Confidence:** HIGH.

**Resolution:** **Encode now, as a short clause (1-2 sentences) inside the refinement note.** Not a separate sub-section. The clause names the fallback: "if the candidate's purpose is ambiguous, render a defer-with-direction verdict naming the ambiguity and pointing back to `/sense-making` (or whichever upstream discipline owns purpose-stabilization in the runner being used)."

### Ambiguity 3: #2/#3 unification placement

**Counter:** Place the unification only as an ancillary update to §4 #2 + #3 (back-references); keep the new refinement note focused on purpose-fitness.

**Why counter fails:** The unification is STRUCTURAL CONTENT of the meta-principle (the prior finding's §3 establishes this). Encoding it only in §4 back-references buries it where practitioners don't encounter it at construction time (Phase 0). The new refinement note's body should ARTICULATE the unification inline so practitioners reading the note understand WHY the test fires.

**Confidence:** HIGH.

**Resolution:** **Both.** The refinement note BODY contains a paragraph articulating the unification (1 paragraph; ~3-4 sentences). The §4 #2 + #3 entries' Prevention texts get ancillary updates with back-references to the new note (Ancillary A + B from surfacing).

### Ambiguity 4: Constructive-output as test — restate or cross-reference?

**Counter:** Restate at Phase 0 so the practitioner doesn't have to navigate to Phase 3.

**Why counter fails:** Restating creates redundancy. The Phase 3 text is correct as-is and is already accessible. A firm cross-reference ("the Verdicts section's constructive-output refinement note") plus a one-sentence framing ("inability to extract a seed is structural evidence the verdict is unsupported") preserves locality without duplication.

**Confidence:** HIGH.

**Resolution:** **Cross-reference.** New refinement note adds a one-sentence framing of constructive-output AS structural test, with a firm cross-reference to the existing Phase 3 note. Phase 3 note unchanged.

### Ambiguity 5: Ancillary edit set — minimum or comprehensive?

**Counter:** Comprehensive (A+B+C+D+E+F) creates better structural coherence by updating all the places where severity-related content lives.

**Why counter fails:** C (Adversarial structure final sentence) and D (Phase 3 constructive-output back-reference) are SOFT — they add coherence but no hard-content requirement. Including them risks scope creep and adds reviewer-friction (more lines to audit). Minimum-set (A+B+E+F) is the responsible default; C and D become COULD items for user discretion.

**Confidence:** HIGH.

**Resolution:** **Minimum set as default.** A + B (mandatory back-references) + E + F (negative confirmations). C and D as COULDs in the finding.

## Phase 2 — Adversarial Evaluation

### W1 — `/navigation` (status quo)

**Prosecution:**
- *D1 LOW:* implies steering toward a destination (English default); the discipline only ENUMERATES — Selector role is separate. Precision mismatch.
- *D8 VIOLATION:* the candidate's strongest defense is "it's already there." Inertia-as-defense.
- *D7 mild:* the noun "navigation" doesn't pair cleanly with the autonomy-ladder role-noun "Navigator" via standard derivation (verb-form → agent-noun is the clean pair, e.g., explore→Explorer; noun-form → agent-noun is awkward).

**Defense:**
- *D2 HIGH:* maximally recognizable; everyone knows what "navigation" means.
- *D3 ZERO:* no switching cost.
- *D6 OK:* fits the noun-cluster siblings (sense-making, td-critique, meta-loop).

**Collision:** Defense's zero-switching-cost + recognizability are real. But the D8 anti-bias test fires: a rename of just one letter (to N4 `/navigate`) gives nearly all the recognizability + small switching cost AND fixes D1 + D7. The bar for "keep status quo" is whether any tighter alternative dominates; N4 does on D1 + D7 at near-zero cost.

**Verdict: REFINE → promote to N4 `/navigate` unless the user's specific user-decision-factor weighting prizes zero cost above all else.**

**Constructive output:** if the user genuinely doesn't want any rename, W1 survives as a principled-keep verdict; the structural defense must explicitly invoke "switching cost trumps the verb/noun shift even though the verb/noun shift is real." Default is to upgrade to N4.

### N4 — `/navigate`

**Prosecution:**
- *D1 mild:* "navigate" derives from same root as "navigation"; same English-default executive-meaning mismatch.
- *Cosmetic-rename objection:* "this is barely a rename; -tion → -e is one letter."

**Defense:**
- ***D7 HIGH:*** fixes verb/noun cluster placement — moves the discipline from noun-cluster to verb-cluster, joining /innovate, /explore, /decompose, /comprehend, /reflect (5 of the 11 disciplines).
- ***D7 HIGH:*** pairs cleanly with autonomy-ladder Navigator role-noun via the standard verb→agent-noun derivation (navigate → Navigator, like explore → Explorer, innovate → Innovator). This is the cleanest cross-layer terminology pairing available among all candidates.
- *D3 MINIMAL:* one-letter rename — folder name (`cognitive_harness/navigation/` → `cognitive_harness/navigate/`) + a few cross-reference updates.
- *D4 HIGH:* "navigate" is already used as a verb in cross-references throughout the project.
- *D8 OK:* not status quo; the rename has structural justification.
- **"Cosmetic" prosecution rebuttal:** the change is STRUCTURAL, not cosmetic. It moves the discipline into the verb cluster (a real categorical shift) AND fixes the role-noun pairing (which currently doesn't compose cleanly: "Navigator" is the role; "navigation" the action — the verb form `navigate` is the missing piece that pairs both layers).

**Collision:** Defense's structural-consistency argument defeats the cosmetic-rename prosecution. The D1 mild concern (same root word) persists but is dominated by D7 + D4 + D6 wins. N4 has the strongest multi-dimensional defense among all candidates.

**Verdict: SURVIVE — top-ranked candidate.**

**Caveats:** none on critical dimensions. The mild D1 mismatch (same root as "navigation") is acceptable because (i) the broad dictionary meaning of "navigate" includes plotting routes, not only following them, and (ii) the verb-form recasts the discipline as ACTIONABLE rather than as an ABSTRACT NOUN, which subtly bias-shifts toward the enumeration-without-execution reading.

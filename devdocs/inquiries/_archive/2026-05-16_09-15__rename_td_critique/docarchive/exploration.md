## Region 1 — The discipline's identity (what td-critique actually IS)

Read from `cognitive_harness/td-critique/SKILL.md` and the canonical reference `cognitive_harness/td-critique/references/td-critique.md`.

### One-sentence definition

> *Structural Critique is the process of reducing a solution space by constructing evaluation landscapes from extracted success criteria, positioning candidates through adversarial testing, and tracking coverage until convergence is reached.*

### Cognitive operation (per the reference)

| Aspect | Content |
|---|---|
| Role in the loop | The **contraction force** — turns divergent thinking (sense-making + innovation expand the space) into convergent results (the candidate set shrinks to verdicted survivors). |
| Two structural operations | **Extraction** (build evaluation framework from sense-making output) + **Evaluation** (apply framework to innovation candidates through adversarial testing). |
| Adversarial structure | **Prosecution** (strongest case against) + **Defense** (strongest case for) + **Collision** (verdict from the confrontation). |
| Outputs | Three verdict types: **SURVIVE** / **REFINE** / **KILL**, each with constructive output (a seed extracted from kills; a refinement target for refines). |
| Coverage tracking | The accumulator — persistent memory across iterations; landscape regions (viable / dead / boundary / unexplored); convergence detection. |

### What the spec EXPLICITLY says the discipline is NOT

The reference invests effort distancing the discipline from common interpretations of "critique." This is a load-bearing signal that the current word "critique" carries baggage the discipline rejects:

- *Not nitpicking* — "nitpicking finds surface flaws without assessing whether they matter; critique evaluates across weighted dimensions with severity awareness"
- *Not judgment* — "judgment is a single verdict from a single perspective; critique is structured adversarial testing across multiple dimensions"
- *Not validation* — "validation confirms something works; critique determines whether something is the *right* thing, not just a *working* thing"
- *Not reviewing* — "reviewing checks for errors; critique constructs the fitness landscape that reveals viability"
- *Not pessimism* — "critique includes defense, not just prosecution — it finds what's strong, not only what's weak"

The discipline performs adversarial evaluation, but it rejects all five common readings of "critique." The name has to do work to overcome these connotations.

### Confidence

CONFIRMED — direct reading of the canonical spec.

## Region 3 — Candidate name space

Possibility-mode, completeness-first: enumerate the obvious dimensions before reaching for novel ones.

### Dimension A — Bare-verb candidates (matching the modal cannon pattern)

| Candidate | Captures | Tension |
|---|---|---|
| `critique` | The current operation, with baggage rejected by the spec | The 5 explicit NOT-list items remain semantic noise |
| `evaluate` | Generic evaluation; neutral | Maybe too generic — every step in the loop "evaluates" something |
| `adjudicate` | Verdict-rendering + (uniquely) the prosecution+defense+collision structure (legal etymology) | Formal-sounding; less casual than sibling names |
| `assess` | Neutral evaluation | Soft; doesn't convey the adversarial structure |
| `vet` | Testing-for-fitness; active connotation | Short, but informal; may not feel weighty enough |
| `verify` | Confirms correctness | Wrong — spec explicitly says critique is NOT validation |
| `sift` | Filtering, reduction (the contraction-force aspect) | Captures contraction but not the verdict-rendering |
| `winnow` | Separating valuable from chaff | Evocative but archaic-sounding; less daily-language |
| `screen` | Filtering candidates | Closer to "validate" semantics; loses verdict-and-construct |
| `select` | Choosing among candidates | The output is closer to a verdict spread than a selection |
| `judge` | Verdict-rendering | Heavy baggage (legal + personal-judgment connotations) |
| `appraise` | Assessing value | Often used in real-estate/art contexts; specific connotation |

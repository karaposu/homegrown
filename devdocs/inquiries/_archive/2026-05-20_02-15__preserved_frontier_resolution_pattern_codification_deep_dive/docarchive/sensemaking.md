## Phase 3 — Ambiguity Collapse

### Ambiguity 1 — 2-level vs flat framework structure (FQ1)

**Strongest counter-interpretation:** "Flat structure with 4 templates (T-A/B/C/D, where T-D = 4-alternative-analysis) is cleaner. 2 levels add unnecessary complexity."

**Why the counter fails (structural grounds):** T-A/B/C operate at per-candidate scope (classify preserved-frontier candidates); 4-alternative-analysis operates at per-sub-piece scope WITHIN a commit decision (calibrate the form of commit text per sub-piece). These are DIFFERENT SCOPE-LEVELS. A flat structure would conflate scopes — operationally suspect because:
- A T-A candidate (e.g., A1) goes through branch-experiment → commit; the commit's form might use 4-alt-analysis per sub-piece. The candidate-level classification (T-A) and the commit-form mechanism (4-alt) are sequential operations at different scopes.
- A T-C candidate (e.g., cross-T-tag pattern) has NO rule-promotion path; 4-alt-analysis doesn't apply because no rule is committed. The "no T-D for T-C" pattern shows 4-alt is NOT a per-candidate classification but a per-commit mechanism.

The 2-level structure honors the scope-level difference; the flat structure obscures it.

**Confidence: HIGH** (structural evidence: 4-alt-analysis's scope-of-operation in 05-00 + 06-00 is per-sub-piece, not per-candidate; this is verifiable in the finding content).

**Resolution:** 2-level framework structure committed.

**Load-bearing concept test applied:** "2-level structure" passes proxy-vs-structural test (real scope-level distinction); user-language-alignment LOW (newly coined; not yet in project vocabulary). Action: pair the name with structural-precise sub-characterization in the finding.

### Ambiguity 2 — T-D positioning name (FQ2)

**Strongest counter-interpretation:** "Commit-form mechanisms" is abstract. Alternatives: "Calibration-discipline mechanisms"; "Per-sub-piece form-selection"; "Commit-decision mechanisms"; "Form-templates"; "Sub-piece templates."

**Why some alternatives are clearer:** "Calibration-discipline mechanisms" (from 05-00's minimum-sufficient calibration discipline) emphasizes the discipline aspect; "Per-sub-piece form-selection" emphasizes the operation; "Sub-piece templates" emphasizes the parallel-to-Level-1 structure.

### Ambiguity 3 — Decision-tree structure (FQ3)

**Strongest counter-interpretation:** "Multi-dimensional 3-tuple lookup is more honest. Test 1 ∈ {NONE, PARTIAL, FULL}; Test 2 ∈ {UNIFY, ADD}; Test 3 ∈ {YES, NO}. Multiply: 3 × 2 × 2 = 12 cells; classify by cell."

**Why the counter fails (structural grounds):** Test 2 is undefined for Test 1 = NONE or FULL. There's no "role" to ask about if there's no existing rule at scope (NONE) or if existing rules fully cover (FULL). Similarly Test 3 is undefined for Test 2 = ADD — there's no fix-wise unity to ask about if the candidate ADDS a new vantage.

The tests are NOT independent; they're GATED by prior outcomes. Sequential decision tree is structurally correct; multi-dimensional classifier is structurally wrong.

The 12-cell lookup would have UNDEFINED cells (most of them); the 4-leaf tree has DEFINED leaves only.

**Confidence: HIGH.**

**Resolution:** sequential decision tree committed. Reachable leaves: NONE → T-A; PARTIAL+ADD → T-A; PARTIAL+UNIFY+YES → T-B; PARTIAL+UNIFY+NO → T-C; FULL → edge case.

### Ambiguity 4 — Trigger-outcome semantics distinctness (FQ4)

**Strongest counter-interpretation:** "All 3 outcomes are 'something happens when the trigger fires.' The distinction (commit / adjudication / re-examination) is descriptive, not structural."

**Why the counter fails (structural grounds):**
- **T-A → commit:** the trigger firing PRODUCES the spec edit (via branch-experiment → spec-edit inquiry). The trigger advancement IS the path to commit.
- **T-B → promotion-inquiry adjudication:** the trigger firing OPENS a new inquiry; the inquiry then adjudicates whether to commit or further preserve. The trigger is necessary but not sufficient for commit.
- **T-C → META-RULE re-examination:** the trigger firing OPENS a re-examination of whether a META-RULE is warranted; the re-examination may conclude (a) no META-RULE (preserve constellation redundancy); (b) META-RULE committed (extends framework); (c) framework extension without META-RULE. The trigger does NOT promote to commit.

The outcomes are STRUCTURALLY DISTINCT — what HAPPENS after the trigger differs in structure, not just description. Conflating them would be the structural error anti-silent-widening discipline prevents.

**Confidence: HIGH.**

**Resolution:** 3 distinct trigger-outcome categories committed. The framework must articulate this distinctness explicitly.

> **Decision tree — classifying a candidate into a template.**
>
> Level 1 classification operates via 3 sequential tests with gated outcomes:
>
> 1. **Test 1 — Scope-coverage check.** Does any existing rule in the discipline operate at the candidate's scope?
>    - Result: NONE / PARTIAL / FULL.

>
> 3. **Test 3 — Fix-wise unity check.** (Gated by Test 2 = UNIFY.) Does a single rule fix the candidate's pattern, or are fixes distributed across multiple primary mechanisms?
>    - Result: YES (single rule) / NO (distributed).

> Test 1 (scope-coverage)
> ├── NONE → T-A capability-gap
> ├── PARTIAL → Test 2 (role)
> │   ├── ADD → T-A (capability-gap; with partial-coverage acknowledgment)
> │   └── UNIFY → Test 3 (fix-wise unity)
> │       ├── YES → T-B structural-consolidation
> │       └── NO → T-C distributed-fix META-observation
> └── FULL → edge case (research-frontier; NOT named template at current calibration)
> ```
>
> **4 reachable named leaves + 1 edge case.**
>
> Why sequential, not multi-dimensional? Test 2 is undefined for Test 1 = NONE (no coverage to assess role over) or = FULL (no role-question; candidate is redundant).

Boundary: the meta-level conceptual space of mapping itself, independent of any specific discipline (`/explore`, `/sense-making`, etc.) and independent of the seven concrete kinds listed in the prior identity-refresh finding (layout, concept, status, coverage/confidence, frontier, possibility, partly-excluded relational).

---

## Territory Overview

The territory naturally organizes into two layered concerns:

**Layer 1 — What IS mapping?** A meta-definition that names the essential structural operation common to all paradigms. This is the "minimum core" question.

**Layer 2 — What KINDS of mapping are categorically distinct?** A paradigm enumeration. The candidates organize into multiple axis-systems; the exploration must surface ALL the axis-systems before adjudicating which ones constitute "paradigms" versus axes or properties.

Twelve regions were probed (some near-neighbors, some orthogonal). Confirmed-absent regions and frontier signals appear at the end.

## Inventory

### Layer 1 — Definitional candidates (what mapping IS at meta level)

| ID | Candidate definition | One-line |
|---|---|---|
| **D1** | Mapping is a structure-preserving correspondence | A relation from source to target that preserves at least one structural feature of the source in the target. Classical math/category-theory framing. |
| **D2** | Mapping is purposive structure-preserving correspondence | D1 + the choice of which structure is preserved is governed by purpose. (D1 alone admits trivial maps; the purpose-clause excludes them.) |
| **D3** | Mapping is the act of producing a navigable surrogate | Mapping produces a target-artifact that can stand in for the source for navigation, communication, prediction, or reasoning. The map is a surrogate. |
| **D4** | Mapping is reducing a thing to a workable representation | Compression / abstraction / simplification framing. Mapping = lossy projection from full source to a useful target. |
| **D5** | Mapping is making the implicit explicit | Items, relations, or possibilities that were latent in the territory become observable in the map. Knowledge-articulation framing. |
| **D6** | Mapping is committing to a frame | The mapper chooses what counts as an "item," what counts as a "relation," and what counts as the "territory's edge." The map is the commitment. Constructivist framing. |
| **D7** | Mapping is asserting existence in a representational medium | The map's basic act is to say "this is there." Existence-claim framing (matches `/explore`'s own §1.1 verb-meaning). |
| **D8** | Mapping is composition: source-structure + chosen-feature + target-medium | A three-place relation: (what's there) + (what to preserve) + (what to render it into). Compositional framing. |
| **D9** | Mapping is the operation that turns "unknown" into "known with confidence" | Epistemological framing: mapping moves territory from off-the-map to on-the-map at a stated confidence level. |
| **D10** | Mapping is irreducibly multi-paradigmatic | There is no single definition that captures all paradigms without losing what makes each distinct; the meta-answer is the *enumeration of paradigms* plus their shared minimum (some version of D1-D2). |

### Layer 2 — Paradigm candidates organized by axis-system

The candidates below organize into axis-systems. Each axis is a dimension along which paradigms can vary. A specific PARADIGM is a coherent point or cluster in this multi-dimensional space — a recognizable "way of mapping."

#### Region A — Axis: WHAT-STRUCTURE-IS-PRESERVED (the math/formal axis)

| ID | Paradigm | One-line |
|---|---|---|
| A1 | **Function paradigm** | Each source element maps to exactly one target element. Preserves single-valued correspondence. Examples: lookup tables; deterministic transformations; `f(x) = y`. |
| A2 | **Relation paradigm** | Each source element may map to multiple target elements; each target may have multiple sources. Preserves connection presence. Examples: graph edges; database joins; "is-related-to" links. |
| A3 | **Morphism paradigm** | Preserves composition / algebraic structure. Examples: homomorphism; isomorphism; commutative diagrams in category theory. |
| A4 | **Metric paradigm** | Preserves distances (or distorts them in measurable bounded ways). Examples: isometries; multidimensional scaling; embeddings preserving similarity. |
| A5 | **Topological paradigm** | Preserves continuity / neighborhoods / openness. Examples: continuous maps; homeomorphisms; knot invariants. |
| A6 | **Probabilistic paradigm** | Stochastic; target is a distribution. Preserves likelihood structure. Examples: Bayesian networks; transition kernels; conditional distributions. |
| A7 | **Order paradigm** | Preserves ordering or partial-ordering. Examples: monotonic functions; rank-preserving maps; hierarchies as preserved partial orders. |

#### Region B — Axis: HOW-THE-TARGET-ENCODES-THE-SOURCE (the representational axis)

| ID | Paradigm | One-line |
|---|---|---|
| B1 | **Iconic paradigm** | Target visually/spatially resembles source. Examples: physical maps; pictograms; floor plans; circuit schematics. |
| B2 | **Symbolic paradigm** | Target uses discrete symbols with no inherent resemblance. Examples: alphabets; type tags; categorical labels; field names. |
| B3 | **Indexical paradigm** | Target points at source via reference/link, without representing structure. Examples: pointers; URLs; file paths; foreign keys. |
| B4 | **Continuous-embedding paradigm** | Source items placed in a continuous space; relationships read off geometry. Examples: word embeddings; t-SNE plots; latent spaces. |
| B5 | **Discrete-structural paradigm** | Target is a combinatorial structure (graph, tree, lattice). Examples: dependency graphs; class hierarchies; XML/JSON trees. |
| B6 | **Sequential paradigm** | Target is an ordered sequence preserving precedence. Examples: timelines; control-flow graphs; narrative chronologies. |

#### Region C — Axis: WHERE-THE-MAPPER-SITS (the epistemic/viewpoint axis)

| ID | Paradigm | One-line |
|---|---|---|
| C1 | **Allocentric (god's-eye) paradigm** | Mapper external to territory; survey view. Examples: floor plans; aerial maps; system architecture diagrams. |
| C2 | **Egocentric (first-person) paradigm** | Mapper-relative; routes from a viewpoint. Examples: turn-by-turn directions; navigation traces; "from here, go..." |
| C3 | **Mechanistic paradigm** | Captures causal / dynamic structure. Examples: process diagrams; circuit schematics; system-dynamics models. |
| C4 | **Categorical paradigm** | Items mapped to classes/types via membership. Examples: taxonomies; classification systems; tag schemas. |
| C5 | **Analogical paradigm** | Cross-domain structural correspondence: source in one domain maps to target in another that shares structural form. Examples: metaphors; analogies; cross-disciplinary frameworks. |

#### Region D — Axis: WHAT-OPERATION-PRODUCES-THE-MAP (the verb/act axis)

| ID | Paradigm | One-line |
|---|---|---|
| D-OP-1 | **Recording paradigm** | Observe-and-transcribe; passive. Examples: surveys; sensor logs; cataloguing. |
| D-OP-2 | **Constructive paradigm** | Infer items from indirect evidence; build map from generative rules. Examples: archaeological reconstruction; phylogenetic trees; theoretical models. |
| D-OP-3 | **Compressive paradigm** | Lossy summarization; trade detail for tractability. Examples: subway maps (vs. geographic); executive summaries; principal components. |
| D-OP-4 | **Projective paradigm** | High-dimensional source → low-dimensional target via chosen perspective. Examples: shadows; PCA; 3D-to-2D rendering. |
| D-OP-5 | **Generative paradigm** | The "map" is a generator function; the target is the set of producible outputs. Examples: formal grammars; parametric families; programmable generators. |
| D-OP-6 | **Predictive paradigm** | Map captures future/inferred states. The target includes counterfactual or predicted items. Examples: weather forecasts; simulation traces; risk maps. |

#### Region E — Axis: WHAT-LEVEL-OF-GRAIN (the scope axis)

| ID | Paradigm | One-line |
|---|---|---|
| E1 | **Element-level** | Unit = individual item; identity-based; atomic. |
| E2 | **Structure-level** | Unit = relation/connection; the map encodes how items hang together. |
| E3 | **Behavior-level** | Unit = process/trajectory; the map captures dynamics. |
| E4 | **Constraint-level** | Unit = what cannot happen; boundary/prohibition-based. |
| E5 | **Possibility-level** | Unit = what could exist; counterfactual / potential space. |
| E6 | **Aggregate-level** | Unit = statistic / property of a collection (e.g., density, average); no single item is the unit. |

#### Region F — Axis: REFERENCE-FRAME (relative to what)

| ID | Paradigm | One-line |
|---|---|---|
| F1 | **Absolute-frame** | Objective coordinates independent of any observer. Examples: GPS coordinates; standard time. |
| F2 | **Relative-frame** | Anchored to a chosen reference object. Examples: "north of X"; "after Y." |
| F3 | **Functional-frame** | Relative to a purpose / use case. Examples: "relevant to inquiry X"; "needed for task Y." |
| F4 | **Egocentric-frame** | Relative to the mapper. Examples: "from where I stand"; "near me." |

#### Region G — Axis: META-LEVEL (mapping of mapping itself)

| ID | Paradigm | One-line |
|---|---|---|
| G1 | **Map-of-mappings paradigm** | A meta-map: how different maps or paradigms relate. The inquiry producing this exploration is itself an instance. |
| G2 | **Self-mapping paradigm** | A system maps itself. Reflexive. Examples: introspection; a discipline's self-description; auto-documentation. |
| G3 | **Process-mapping paradigm (of the mapping act)** | Records the mapper's trajectory: telemetry, provenance, scan order. Examples: `/explore`'s Progression section; git history; lab notebooks. |
| G4 | **Boundary-mapping paradigm** | Maps the limits of the map's own coverage. Examples: frontier sections; "here be dragons"; confirmed-absent regions. |

#### Region H — Axis: ORIGIN / EPISTEMIC SOURCE

| ID | Paradigm | One-line |
|---|---|---|
| H1 | **A priori paradigm** | Derived from logical/structural first principles. Independent of observation. Examples: mathematical theorems; abstract type systems. |
| H2 | **A posteriori paradigm** | Derived from observation / empirical evidence. Examples: surveys; experiments; data-driven maps. |
| H3 | **Generative-rule paradigm** | Derived by applying rules to inputs. Mixed (rules a priori; instances a posteriori). Examples: grammar-parser maps; rule-based ontologies. |
| H4 | **Discovered-vs-invented axis** | Does the map capture a pre-existing structure (discovered) or impose one (invented)? Realism vs constructivism in epistemic position. |

#### Region I — Axis: OUTPUT FORM (the map's shape)

| ID | Paradigm | One-line |
|---|---|---|
| I1 | **Catalog/list form** | Flat enumeration; minimal structure. |
| I2 | **Graph/network form** | Nodes and edges; relational. |
| I3 | **Field/continuous form** | Values defined over a continuous domain. Examples: temperature fields; relevance fields. |
| I4 | **Hierarchy/tree form** | Strict containment or generalization. |
| I5 | **Manifold/topological form** | Continuous structure with neighborhood relations. |
| I6 | **Trajectory/path form** | Ordered sequence through states. |
| I7 | **Matrix/table form** | Cells indexed by two or more axes. |

#### Region J — Axis: PURPOSE (why map)

| ID | Paradigm | One-line |
|---|---|---|
| J1 | **Navigation purpose** | To traverse / locate / plan routes. |
| J2 | **Communication purpose** | To share understanding. |
| J3 | **Prediction purpose** | To anticipate future states. |
| J4 | **Decision purpose** | To choose among alternatives. |
| J5 | **Reasoning-substrate purpose** | The map IS the thinking medium; reasoning happens in / on it. |
| J6 | **Memory / archival purpose** | To preserve / record what was there. |
| J7 | **Coordination purpose** | To synchronize multiple actors on a shared view. |

#### Region K — Axis: TEMPORALITY

| ID | Paradigm | One-line |
|---|---|---|
| K1 | **Static paradigm** | Snapshot at one point in time. |
| K2 | **Dynamic paradigm** | Captures change over time. |
| K3 | **Counterfactual paradigm** | What could be, not what is. |
| K4 | **Historical paradigm** | What was; archival. |
| K5 | **Predictive paradigm** | What will be; extrapolation. |

#### Region L — Axis: FIDELITY (how faithful to the source)

| ID | Paradigm | One-line |
|---|---|---|
| L1 | **Lossless paradigm** | Preserves all information; reversible. Examples: bijective encodings; lossless compression. |
| L2 | **Lossy paradigm** | Preserves selected information; not reversible. |
| L3 | **Lossy-with-error-bound paradigm** | Quantified loss; approximation with known bounds. Examples: ε-net; controlled-error compression. |
| L4 | **Pathological/distorted paradigm** | Deliberately distorts for emphasis. Examples: subway maps (vs geographic accuracy); caricatures; persuasive diagrams. |

These 12 crystallized paradigms are recognizable "ways of mapping" — chunky enough that someone could ask "is this a Cartographic mapping or a Relational mapping?" and get a meaningful answer.

The prior identity-refresh finding's 7 kinds (layout, concept, status, coverage/confidence, frontier, possibility, partly-excluded relational) appear to map roughly onto:
- layout → P-CART (cartographic) + P-REL (relational, when topology only)
- concept → P-TAX (taxonomic) when about classes; P-REL when about relations between concepts
- status → P-COV (field) when continuous; P-TAX when categorical
- coverage/confidence → P-COV (coverage / field)
- frontier → P-CONST (constraint/boundary)
- possibility → P-POSS (possibility/generative)
- partly-excluded relational → P-REL (relational, partly excluded because full meaning belongs to sense-making per the NOT-list)

This suggests the prior finding's 7 kinds were a subset of the broader paradigm space, partitioned by what `/explore` is OBSERVED to produce — but the meta-paradigm space includes paradigms `/explore` doesn't currently produce (e.g., P-FUNC, P-EMB, P-PROC, P-NAV, P-REFL, P-ANALOG).

### Jump-scan (Failure Mode 3 prevention)

Deliberately scanning in directions not yet probed:

| Direction | Surface |
|---|---|
| **Mapping in non-discrete domains** | What if the source is a continuum (e.g., a temperature field), not a set of items? Surfaces P-COV (coverage/field paradigm) — already in inventory but worth reinforcing. |
| **Mapping in absence of a mapper** | Does a map exist if no one reads it? The structural-versus-functional question. Surfaces a deferred frontier signal but no new paradigm. |
| **Anti-mapping / Borges scenarios** | Borges' "On Exactitude in Science" — a 1:1 map equals the territory. Surfaces the L1 (lossless) edge case; reinforces that L1 is a degenerate paradigm where the map and the territory collapse. |
| **Mapping under deception / misdirection** | Maps designed to mislead (propaganda maps, false-flag schematics). Surfaces L4 (pathological paradigm) — already in inventory. |
| **The act of NOT mapping** | Choosing not to map a region; deliberate ignorance. Surfaces the confirmed-absent annotation as a paradigm-level move (you can map an absence). Reinforces G4 (boundary-mapping). |
| **Real-time vs offline mapping** | Mapping that updates continuously (e.g., live cursor positions) vs mapping that produces a static artifact. Surfaces K1 vs K2 temporality, plus a process-mapping nuance. No new paradigm, but reinforces the temporality axis. |
| **Maps as commitments** | Once produced, a map commits the producer to certain views; revising the map = revising commitments. Sociological framing. Touches purpose paradigm (J2 communication, J7 coordination) but no new paradigm. |

## Gaps and Recommendations

### Gaps in the meta-paradigm map

- **The composition algebra.** Can paradigms be composed? (E.g., does P-CART + P-PROC = a mapped trajectory in space?) The exploration surfaces that compositions exist in practice but does not adjudicate the composition rules. Sensemaking should address.
- **The "axis" vs "paradigm" framing tension.** Both are valid; sensemaking should adjudicate the primary frame for the answer. Most likely the answer is BOTH (axes generate the space; paradigms are recognized clusters).
- **The discipline-paradigm mapping.** Which paradigms does `/explore` produce vs `/sense-making` vs `/decompose`? This is a follow-up applied question; not load-bearing for the meta-definition.

### Recommendations for downstream disciplines

- **Sensemaking** should adjudicate:
  1. Which definitional candidate (D1–D10) is the load-bearing minimum-core.
  2. Whether the answer is axes-only, paradigms-only, or axes+paradigms.
  3. Which crystallized paradigms (P-*) are genuinely distinct vs which collapse into others.
  4. How the prior 7-kinds typology maps onto the meta-paradigms (preserve / correct / reposition).

- **Decomposition** should partition:
  1. The minimum-core definition from the paradigm enumeration (these are two pieces).
  2. The axes from the crystallized-paradigms (two layers).
  3. The relationship-to-prior section (REFINES the identity-refresh finding).

- **Innovation** should generate:
  1. The concrete final framing — likely a definition + axes + crystallized paradigms structure.
  2. How this gets applied to `/explore` (an addition to the `/explore` spec? a separate meta-doc? a frame that informs Step 0?).

## Goal

A ready-to-commit operational specification for A1 that the downstream innovate-redesign inquiry can use as direct input for the spec edit. The output must:

(a) Be CONCRETE ENOUGH that an LLM running the innovate discipline can apply A1's predicate deterministically (specific signals, not abstract instructions).

(b) Be INTEGRATED with the existing innovate spec features (Inversion depth-check; Constraint Manipulation both-direction; Absence Recognition redesign-level; axis-coverage check) — A1 should ORCHESTRATE these existing features against detected inheritance, not duplicate them.

(c) Be DISTINCT from the diagnostic-series candidates that address inheritance at narrower scopes (Pair 5's Q3 piece-level Inversion at meta-decision pieces; Pair 7's Q3-extension intervention-shape-axis Inversion; Pair 8's §9 seed-time methodology-mode consideration; Pair 1's V2 re-test trigger). A1 is the meta-trigger that these scope-specific rules SERVE; A1's job is detection + orchestration; the scope-specific rules' job is the per-scope mechanism application.

(d) Be EMPIRICALLY VALIDATED by hypothetical-seed testing on at least 3-5 of the 8 in-scope diagnostic cases — would A1's predicate have fired on the original failing innovate runs, and would A1's design have produced the corrections the human stepped in for?

(e) Pass 01-30's T1-T5 boundary verdict (output-shape: novel content via frame-alternative candidates; novel-vs-existing: creating new; input-type: seed/piece-list; order-in-loop: between Phase 2 Generate and Phase 3 Test; content-vs-process target: content under inquiry — the inherited frame).

(f) Honor the user's accumulated parsimony preference: A1 is a bounded extension within innovate's existing 2-operation + 7-mechanism + 5-test-cycle + 6-failure-mode structure. NOT a broad rewrite; NOT a new top-level operation.

The downstream redesign inquiry consumes this output + the 8 diagnostics' other candidates + 01-30's 2-improvement boundary + the synthesis's 3 cores → commits actual spec text to innovate reference.

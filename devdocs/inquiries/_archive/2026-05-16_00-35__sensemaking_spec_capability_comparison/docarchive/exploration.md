## Gaps and Recommendations (Frontier Questions for Downstream)

Handed to downstream disciplines:

**To Sensemaking (S):**
- What does "capability" actually mean in the context of a discipline reference spec? Possible anchors: (a) the set of cognitive operations the discipline can perform; (b) the set of failure modes it detects; (c) the operational explicitness of when/where to apply each operation; (d) the spec's resistance to mis-application by the LLM running it; (e) the spec's scalability (how it accommodates future checks).
- Are the 7 new subsections in R6 instances of one underlying capability addition, or are they distinct capability additions?
- Is the runtime firing schedule (R6 "How the meta-question fires at runtime") a SUFFICIENT condition for "more capable," or only a necessary one?

**To Decomposition (D):**
- Decompose the capability question into independent sub-questions: (i) does the draft enable new operations? (ii) does it improve operational explicitness of existing operations? (iii) does it improve the spec's evolvability? (iv) does it carry costs (cognitive load, maintenance) that offset gains?

**To Innovation (I):**
- Generate verdict candidates: draft strictly dominates, live strictly dominates, equivalent in capability, draft dominates on dimension X but not Y, merged version dominates both.

**To Critique (C):**
- Kill verdicts that don't survive: capability claims with no observable test, verdicts that assume the firing schedule's value without evidence, verdicts that ignore the cost/maintenance angle, verdicts that assume the draft is "more correct" without checking for regressions.

**Frontier observations (not for any specific discipline):**
- The draft is **structurally additive** — no regressions, only additions. This biases the verdict toward draft-wins on pure-capability grounds, but the absence-of-regression should be verified by Critique.
- The draft is **not loaded** by SKILL.md at runtime. Even if the draft is more capable on paper, the live discipline running today gets the live spec's capability, not the draft's. Promotion of the draft would change this; archiving it would not.

## Phase 2 — Generate

### Section ordering (cross-piece sub-choice)

Three candidates considered:

- **Order A — Chronology first, then phase narratives, then open threads + cross-cascade.** Reader gets data spine first, then narrative arc, then frontier. Pros: data spine establishes citation surface up front. Cons: 68-row table at the top may overwhelm.
- **Order B — Phase narratives first, chronology as appendix, then open threads + cross-cascade.** Reader gets narrative immediately; data is reference. Pros: easier reading entry. Cons: citations require flip-back to appendix.
- **Order C — Brief executive snapshot (current state of navigation today), then phase narratives, then chronology appendix, then open threads + cross-cascade.** Reader gets a "where are we now" header before the historical narrative. Pros: orients reader before time-traveling. Cons: a fourth structural element to balance.

**Mechanism applications:**
- *Combination:* combine the established-audit shape (finding 44 led with "what's established as of now") with the chronological survey shape → Order C is the combination output.
- *Lens shifting:* under "reader who hasn't followed the navigation corpus" frame, Order C orients best. Under "reader who has followed but wants citations" frame, Order A is best.
- *Inversion:* invert "narrative first" → "data first" → Order A. Invert "current state first" → "history first" → Order B.
- *Domain transfer:* from technical-writing convention, an executive snapshot followed by historical detail is standard for survey docs.

**Survives:** Order C — brief executive snapshot + phase narratives + chronology appendix + open threads + cross-cascade. The opening snapshot solves the "reader's orientation" problem; the chronology stays as data spine at the end (appendix), not as opening table.

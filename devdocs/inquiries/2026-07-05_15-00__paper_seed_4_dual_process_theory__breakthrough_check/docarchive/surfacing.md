## PART 1 — The paper's concepts (FACTs A-*), substrate + off-domain apps quarantined

- **A-1 [core] The core dichotomy: two modes of thought.** *"an implicit (automatic), unconscious process and an explicit (controlled), conscious process."* **System 1** = fast, automatic, associative, intuitive, effortless, high-capacity, habit-based, hard to change. **System 2** = *"slow and sequential… domain-general, performed in the central working memory system… limited capacity… rule-based, analytic, controlled, demanding of cognitive capacity, and slow."* FACT. Functional residue: **two thinking modes — a cheap fast associative one and an expensive slow rule-following one.**

- **A-2 [core] System 2 runs IN working memory and is capacity-limited.** *"domain-general, performed in the central working memory system. Because of this, it has a limited capacity."* De Neys: burdening working memory impairs System 2 but not System 1 (*"System 1… works independent of working memory"*). FACT. Functional residue: **the slow deliberate mode consumes the scarce working-memory/context budget; the fast mode does not.**

- **A-3 [supporting] "Automatic" is not binary — it decomposes (Bargh).** Four components: *awareness, intentionality, efficiency, controllability* — *"a component view… as opposed to… an all-or-none dichotomy."* FACT. Functional residue: **fast/slow is a graded bundle of properties, not a clean switch.**

- **A-4 [core] Heuristic-then-analytic: the fast mode SELECTS what's relevant, then the slow mode reasons on it (Evans).** *"during heuristic processes, an individual chooses which information is relevant… Relevant information is then processed further whereas irrelevant information is not. Following the heuristic processes come analytic processes."* FACT. Functional residue: **a fast relevance-filter runs FIRST and hands a pruned set to the slow reasoner — a serial pipeline, not parallel.**

- **A-5 [core, the standout candidate] Cognitive steering: System 1 is a SERIAL steering processor for System 2 (Walker).** *"system 1 functions as a serial cognitive steering processor for system 2… a heuristic orientation system is required to align varied, incoming environmental data with existing… processes… a conscious state emerges from effortful associative simulation, required to align novel data accurately with remote memory."* And the failure law: *"'rubbish in, rubbish out'… errors will always occur if the accuracy of initial retrieval and location of data is poorly self-regulated."* FACT. Functional residue: **a fast orientation/steering layer aligns incoming data with existing memory BEFORE the slow analytic work — and if that orientation is bad, the downstream reasoning is doomed regardless of its quality.**

- **A-6 [core] Fuzzy-trace: verbatim vs gist, encoded IN PARALLEL, decaying at different rates.** *"verbatim is memory for surface information… gist is memory for semantic information… we encode, store, retrieve, and forget the information in these two traces… separately and completely independently… verbatim decays quickly, while gist lasts longer… as we mature we increasingly rely more on gist information over verbatim."* FACT. Functional residue: **surface-detail and meaning-gist are stored as two parallel traces from the start; the detailed one fades faster; maturity = leaning on gist.**

- **A-7 [supporting] System 2 monitors/overrides System 1, but only weakly (Sloman).** The rule-based system *"had control over the associative system, though it could only suppress it."* FACT. Functional residue: **the slow mode can veto the fast mode's output, but not author it — a monitor/veto relationship.**

- **A-8 [supporting] Belief bias / the arbitration failure.** When fast belief-based output conflicts with slow logic, and working memory is loaded, the fast wrong answer wins (De Neys, Tsujii-Watanabe). FACT. Functional residue: **under context pressure, arbitration defaults to the fast mode — even when it's wrong.**

- **A-9 [supporting] The LLM application (already in the wild).** *"'fast thinking,' direct… response… and 'slow thinking,' which involves… chain-of-thought… 'tool calls'… and intermediate verification… 'tool-augmented thinking'… DPT-Agent… System 1… finite-state machines for… low-latency actions, while a System 2 component handles complex intentions and… reflection."* FACT. Functional residue: **in LLMs the mapping is already conventional — direct answer = System 1; chain-of-thought / tools / verification = System 2.**

- **A-10 [core, the honesty anchor] The dichotomy is CONTESTED.** Evans' 5 fallacies (*"There are clearly more than just two cognitive systems"*; *"Both System 1 and System 2… can lead to normative answers and both can involve cognitive biases"*); the DGC single-system *continuum* alternative; Moshman's 4-type division. FACT. Functional residue: **the clean 2-system story is a useful simplification, not settled truth — importing it as fact would launder a contested model.**

### Quarantined (DOESN'T-APPLY — substrate + off-domain apps; import test bars these)
- Neural substrate (PFC / vmPFC / IFC / anterior cingulate, fMRI/NIRS, brain hemispheres). Off-domain applications: stereotyping, terror-management, moral dilemmas (trolley), religiosity/"analytic atheism," economic multiple-selves, habituation, persuasion/attitude-change (ELM central/peripheral routes). These are the paper's bulk and are **out** — no substrate, and a thinking-harness is not a social perceiver.

## PART 3 — The mapping (HAVE / LACK / DOESN'T-APPLY / REVERSE)

### HAVE — the paper names something we already have
- **M-H1 [core]** A-1 (System 1 vs System 2) ↔ our **Intuition primitive + fast base model** (System 1) vs the **deliberate discipline pipeline** (System 2, B-2). The whole harness IS a System-2 externalization; /intuit + the base model IS System 1. **Largely already ours** — candidate *confirming*. (Test: does framing the harness explicitly as "the System-2 organ" ADD anything, or just relabel?)
- **M-H2 [core]** A-5's arbitration/monitoring + A-7 (System 2 monitors/vetoes System 1) ↔ our **Metacognition primitive** (monitor + adjust; the "I'm stuck" signal). Already a primitive. *Confirming.*
- **M-H3 [core]** A-6 (verbatim/gist) ↔ **consolidation** (B-3, episodic→semantic gist). Same distinction from a different literature. *Confirming* — but with a possible *refinement* (see M-L2).
- **M-H4 [core]** A-5 (cognitive steering: fast orientation aligns data with memory before slow analysis; "rubbish in, rubbish out") ↔ **warming / cold-navigation** (B-4). Strikingly close — even the *term* "cognitive steering" matches our steering canon. *Confirming* — but the "rubbish in→rubbish out" *gating law* may sharpen it (see M-L1).
- **M-H5 [supporting]** A-2 (System 2 runs in capacity-limited working memory) ↔ **reach≠grasp** (B-5) + the deliberate disciplines consuming the context budget. *Confirming.*
- **M-H6 [supporting]** A-4 (fast relevance-filter feeds the slow reasoner) ↔ **surfacing** (select relevant) feeding the analytic disciplines. *Confirming.*
- **M-H7 [supporting]** A-9 (LLM fast/slow) ↔ our harness is exactly the "slow thinking" externalized. *Confirming, and already conventional.*

### LACK — the paper names something we plausibly need but lack a concept for
- **M-L1 [supporting — the strongest candidate] The steering-GATES-analysis law ("rubbish in, rubbish out").** A-5's sharp claim: *the quality of the fast orientation caps the quality of the slow reasoning, no matter how good the reasoning is.* We HAVE warming and cold-navigation (B-4), but do we state it as a **gating law** — that a well-run traverse on a badly-oriented start is still doomed? Candidate: a named *gate* (orientation quality is a ceiling on downstream quality), sharper than "cold-navigation makes tidy-but-wrong maps." [external-anchor to test in sensemaking: does the steering canon already state the *gating/ceiling* relationship, or only that cold-nav produces bad maps?]
- **M-L2 [supporting] Parallel verbatim/gist encoding (vs transformation).** A-6 says verbatim + gist are encoded **in parallel from the start**, and verbatim just *decays faster* — NOT that episodic *transforms into* semantic. Consolidation (B-3) modeled it as a *transformation over time* (episodic→semantic). Candidate: a **refinement to consolidation** — maybe gist isn't produced *from* episodic later, but *co-encoded* and surfaced by differential decay. [test: does this change anything meaningful for us, or is it a distinction without a difference at our grain?]
- **M-L3 [peripheral] The fast/slow ARBITRATION policy (when to deploy which).** A-8 (belief bias: under load, the fast wrong answer wins) raises: does our harness have an explicit *policy* for when to spend the expensive slow pipeline vs trust fast intuition? We have Metacognition (monitor) but maybe not an explicit *arbitration/escalation* rule. Candidate — but likely premature (mechanism-flavored) and arguably already the runner's job.
